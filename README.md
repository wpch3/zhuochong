## 新项目：ZhuoPet · 桌宠

> 一个真正能用的 AI 桌面伴侣：原创分层 Live2D 风格模型、会呼吸和眨眼的物理身体、本地大脑、长期记忆、语音、换装，以及可选的云端大模型。

```bash
cd zhuopet
npm install
npm run dev        # 预览 http://localhost:5173
npm test           # 48 项测试
npm run build      # 生产构建
npm run electron   # 桌面端（需先 npm install 下载 Electron 二进制）
```

### 已实现

- **原创分层模型**：33 个可动部件、16 组参数、9 种表情、9 个动作、4 种发型、4 套服装、4 个角色。
- **物理与生命感**：双马尾/呆毛/猫耳/猫尾弹簧物理、呼吸、眨眼、视线跟随、歪头、被拎起、睡着冒 Z。
- **本地 AI 大脑**：意图识别、情绪、长期记忆（记住/回忆/遗忘）、关系等级、主动陪伴，完全离线。
- **可选云端**：OpenAI 兼容接口，流式输出，失败自动回退本地。
- **语音**：浏览器语音合成 + 语音输入，可调音色/语速/音调/音量。
- **桌面端**：Electron 透明窗口、托盘、全局快捷键、小窗桌宠、鼠标穿透、位置记忆。
- **模型工坊**：实时调参、骨骼/网格叠加、表情预设、导出 PNG / 模型 JSON / SVG。
- **完整 UI**：首次引导、聊天抽屉、记忆面板、换装栏、右键菜单、设置、沉浸模式、移动端适配。

### 说明

- 模型是原创的分层 SVG 格式，参数命名与 Live2D Cubism 对齐，但**不是** Live2D 官方 `.moc3`，不包含任何官方素材。
- 所有数据只存本机；云端 API Key 只存在本地，导出备份时自动清空。
- 旧项目里那些“等美术完美再提交”的循环没有继续。新项目先交付能用的版本，再逐步打磨。

## 旧项目（参考，已废弃）

根目录的 C 项目是历史上的一个尝试：纯 C 微内核 + 自研 JSON 骨骼渲染 + Windows 分层透明窗口。它验证了一些底层思路（消息总线、状态机、弹簧物理、配置 schema），但美术、UI、AI 和完成度都没有达到可交付状态，最终被放弃。

保留它只是为了：

- 参考角色设定（小寻的配色、性格、发型方向）。
- 参考底层状态机/物理/配置校验的思路。
- 记录踩过的坑（例如不要用 `alpha=0` 挖洞处理遮挡、不要死绑长发、不要等完美才提交）。

**不要再用旧项目构建或运行它。** 新项目在 `zhuopet/`。
