# 黑描边 Chibi：发梢接缝复核试装

这是 `../live2d_chibi_human_blackline_clean/` 的独立后续副本，原黑线版及之前的 13 像素清边版均保留。放大查看各透明切件时，发现身体切件上存在一段游离于头发下方的深色横线（画布坐标 `(412–415, 465)`）。本次只移除这 4 个像素，记录在 `seam_report.json`；脚本逐像素检查原 RGBA，源发生变化时拒绝继续，不扩大删除到相邻发丝。其他切件字节不变。

## 真实观察

已在 C 引擎采样睁眼、闭眼、张嘴、头向一侧和半周期后另一侧，实际打开浅/深底全图与脸颈放大帧。独立深色短线已从身体切件消失；样本中没有观察到大片发丝被删。**发梢/领口附近仍有浅紫或粉紫毛边，另一侧发梢也可见粉点；切件在头动时可能露出不自然的断边。** 不视为接缝、美术或全动作通过。原素材为 AI 整图差分，未具备真实的遮挡底图；需要可编辑分层源、人工补画、更多姿态及用户验收。鲸鱼发夹保留，兽耳和兽尾未使用。

## 复现

```sh
python3 tools/build_human_chibi_seam_review.py # 需要 Pillow
make test-human-cleanup
python3 tools/preview_live2d_chibi.py --seam 5207
# 另一个终端，用安装了 Pillow/numpy 的 Python；此命令会控制该预览：
python3 tools/capture_human_chibi_study.py --seam
```

`qa/` 为真实 C 透明帧、浅深底合成和局部放大；`head_opposite` 取头动后再走约半周期，不代表完整动画验收。指标与初版清边相同：眼 2714/2534、嘴 296、头动 32083、头动身体 0 像素。自动指标不代替目视；预览无认证，仅在可信环境使用，不存敏感信息。
