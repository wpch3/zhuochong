# Chibi 衣身隐藏侧片：隔离试验，未验收

`jacket_sides.svg` 是在 480×512 身体局部坐标中单独绘制的布片、褶皱和阴影，可修改路径、渐变和色值；目前右侧为镜像，仍需依照光照和原画人工细化。`jacket_sides_v1_not_approved.svg` 保存第一次失败形状。此试作不是原始分层 PSD，也没有绘制完整肩、上臂、前臂和手的隐藏结构，不等于成品。

生成器从旧 seam 试装原身体和动态试装袖手分离出**没有程序延色条**的真实身体切片：袖手原画非透明处从身体层移除，再把新绘侧片放在该切片之下并烘焙为身体图。原画和已有试装不改。它不是旧补画工具的安全掩膜流程，不能假设所有缩放下中立不变。

## 重现

需要 Pillow、numpy、`resvg-py==0.5.0`、C 编译器和 Node（浏览器测试还需 Playwright/Chromium）；安装到隔离 Python 环境，不要向仓库提交依赖缓存。

```sh
make build/zhuochong_preview
python tools/build_chibi_underlay.py build/chibi-underlay-v2
python tools/compare_chibi_underlay.py build/chibi-underlay-v2 build/chibi-underlay-qa
python tools/preview_live2d_chibi.py --dynamic --dynamic-study build/chibi-underlay-v2 --preview-root build/chibi-underlay-preview 5218
make test-chibi-underlay
```

候选和比较输出必须是 **新建** `build/` 子目录；生成器验证来源 rig、身体与两袖的哈希和坐标，严格拒绝既有路径。预览无认证，只用于沙箱，不放秘密。`qa/` 下是本轮实际 C、浏览器截图和结果。`.zproj` v1 包含 rig 和 11 张 PNG，**不包含 SVG 来源**，需单独保存本目录，不能误称为 PSD 或 Cubism 工程。

## 执行结果与目视结论

- 第一版新侧片在深底下肩部外侧出现突出的白色弧边；修改路径收窄肩部和下端后，第二版去掉了该明显肩部突起。无遮挡的身体侧片不再是水平拉伸条，但形状仍过于简化、镜像对称，尚未建立可信的衣物结构。真实 C 帧与两极浅/深底均看过：袖侧仍能见细线、局部衔接不自然。**第二版不批准为正式素材。**
- AI 去袖生成尝试只作为参考：它输出白底、整体平面图及新颈部细节，并未给出真实独立肩袖或可靠透明图层；`qa/ai_arms_removed_not_used.png` 留作失败证据，**没有使用其像素作为本试装素材**。新侧片是本目录可编辑 SVG，而非自动补画出的完整原画。
- 两次独立 C 基线在各测试帧逐像素一致后才计算差异；第二版中立帧在缩放 0.35/0.55/0.8/1.0 相对基线分别差 176/269/342/0 像素；0.55 向外/向内为 601/127。它说明不同缩放的差异真实存在，但不说明差异必然是坏画或修复。`qa/v2_metrics.json` 有完整 12 组结果。只测固定步进、中立及两袖 ±2°，不是对全部缩放和动作的保证。
- 真实 C 验证袖手、头、呼吸、眨眼、嘴型、动作循环和物理回稳；真实 Chromium 验证快速拖动、最终值及复位，界面标明试验和局限。`.zproj` 创建、验证、解包 12 文件全部一致，重新载入 C 在 0.55 的三个指定姿态帧逐像素一致。
- 自动验证只覆盖本工作包，不等于编辑器、插件、正式模型全部可用；旧正式资源问题及 Windows 真机尚未解决。后续须分别画出完整肩部、袖子的运动重叠、上臂/前臂/手，改进眼白/虹膜、网格与遮罩，再以组合动作和美术审查决定是否扩大摆幅。
