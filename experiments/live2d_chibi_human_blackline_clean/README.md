# 黑描边无兽特征 Chibi：局部清边试装

这是从 `../live2d_chibi_human_blackline/` 派生的隔离试验，原黑线与有兽特征、桌宠和少女资产均不覆盖。由于放大观察发现发梢左下与领口交界有紫红碎点，本版仅在画布范围 `[390,455,465,470)` 查找透明度大于 32、最多 12 像素、全图 8 连通且位于该范围内的独立小岛，并要求岛中有紫红色；删除 `body` 9 个像素、`head` 4 个像素。具体坐标见 `cleanup_report.json`；其他部件逐字节复制。不是全图清色或手绘补画。

## 实际观察与局限

已实际打开 C 引擎浅/深背景全图、睁眼、闭眼、头动及局部放大图（`qa/*_detail.png`）：主要轮廓、眼口、衣领和头发在这些静态样本中仍可见，未发现此次 13 像素清理造成明显大片发丝缺失。**左侧发尾与领口处仍可看到零散细点/毛边，转头时也存在；不能说已经修好接缝或美术通过。** 这些可能与连接到较大形状的色块及低透明边缘有关，尚未确认，不能据此盲目扩大自动删除。后续需在可编辑分层源上人工逐帧处理，并检查更多动作、浅中深背景与用户审阅。

这是基于 AI 整图差分的实验切件，不是完整分层生产源，不代表 Live2D Cubism 或可用于正式发行。可见鲸鱼发夹保留；本试装去掉的是兽耳、兽尾。

## 复现

```sh
# 需要 Pillow；make 测试用能导入 Pillow/numpy 的解释器
python3 tools/build_human_chibi_cleanup.py
make test-human-cleanup
python3 tools/preview_live2d_chibi.py --clean 5206
# 另一个终端，需要 Pillow/numpy；会复位并驱动这个预览：
python3 tools/capture_human_chibi_study.py --clean
```
