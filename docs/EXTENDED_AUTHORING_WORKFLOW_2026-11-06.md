# 长工作流计划：自研模型与作者工具

用户要求不要每做一小段就停止；每轮以一个可复验的端到端工作包为单位，先列目标，再连续完成编码、素材/模型试验、真实运行、目视、回归和云端备份。不能为了把计划打勾而把未经验证的功能或美术称为完成。桌宠、带兽特征 Chibi、无兽特征 Chibi 和少女始终独立，原始/正式素材不覆盖；自研 zrig 不是官方 Cubism。

## 本工作包（连续实施，不在中间交付）

1. **研究与风险核实**：读取现有编辑器、C 网格坐标和测试；查阅官方控制点操作教程。明确 zrig 规则网格与 Cubism 的 Bézier 网格不同；静态画布不可冒充 C 渲染。
2. **可视关键形态工具**：在已有数值关键形态上加选定关键值的网格叠加和控制点拖动、正确处理素材像素位移与部件平移/缩放/旋转，拖动只产生一次可撤销事务；不可编辑时拒绝而非猜测。新增边界、旋转、缩放、取消拖动、撤销和 UI 测试。
3. **真实运行闭环**：生成独立示例 rig，用 C 引擎测试关键值/中间值与恢复，保存可重现的真实帧，目视检查并记录局限；下载副本而不是写入正式 rig。
4. **模型视觉工作**：继续对黑描边清边试装进行多底色、面部/头动和发尾接缝放大目视；只有确认能安全改善的局部修改才采用，否则保留原样并记录具体残留。必要时进行隔离实验，不能扩大自动删除范围损伤发丝。
5. **验收与交付**：运行编辑器及 C 集成、工程包、清边、网页、预览动作测试与 `git diff --check`；尝试真实浏览器交互，失败明确说明；记录历史自检失败。汇总结果与下一工作包，再提交并推送当前会话分支，确认远端结果。

## 本工作包实施结果

- 关键形态网格现可在静态画布上显示关键值线框并拖控制点，松开为一个事务，取消不提交。验证了位移、旋转、非等比缩放、错误关键值和不支持的链/权重；C API 坐标对照覆盖中间态。画布不画实际扭曲贴图、没有组/动作动态预览，不能代替 C 引擎。
- 使用 `playwright-core@1.65.0` 和 `@sparticuz/chromium@153.0.0` 在真实浏览器完成载入、参数绑定、网格拖点、取消、撤销/重做、JSON 下载。将该下载文件加载进 C，引擎的中间态、极值和返回值行为通过。`tools/rig_editor/qa/` 留下截图、rig 和 C 帧；已目视全页面、画布及 C 双帧。身体全图变形导致袖子及衣服一起扭曲，不能作为生产绑定。
- 对模型分别放大审视头和身体切件，确认此前 13 像素清理后身体层仍有孤立的深色四像素短线；独立生成 `experiments/live2d_chibi_human_blackline_seam/`，仅移除这四点并设置原值保护。C 帧实际看过浅/深背景、闭眼和头两侧：紫色毛边与接缝风险仍在，不能称为精修通过；保留所有前版。
- 修正 ROADMAP 计数后，静态自检从两项失败减少为一项（正式 chibi/teen 生成器指纹）。在 `build/rig-generator-audit/` 中复制两套正式形态、仅在隔离副本运行当前生成器并对比：chibi 候选除了指纹，还更改 ID（`小寻_teen`→`小寻_chibi`）和头部交互区域 rect（`[196,0,453,718]`→`[136,0,575,718]`）；teen 候选除了指纹，还重排 `surprised` 动作中的 7 条通道。即使可能合理，也不能凭静态差异断定行为和视觉不变；正式 rig 一律未覆盖。后续应对交互 hitbox 与动作顺序做真实运行/视觉对比，经验收后再决定是否更新。
- 回归：C 快速单测 2646 通过，网页 266 通过，预览动作与零告警编译、编辑器/C 顶点对照、真实 Chromium 导出→C、工程包及两版清边测试通过。C 快测未含两万帧 soak；旧 chibi 预览仍有 3 条加载警告；静态自检 772 项中 1 项失败，不能称为全量通过。
- 当前留待后续工作包：真实实时 C 预览、图像真正随网格变化、素材的独立臂手和遮挡补画、跨浏览器及用户视觉验收、完整插件工程。无认证预览只用于可信环境。

## 后续完整生产路线（不得误称已完成）

- **作者工程和导入**：源图/分层工程保存、许可清单、非破坏性重导入、外部动作/表情依赖、可恢复工程和版本迁移；验收为少女外链资源完整往返及损坏/恶意输入测试。
- **真实建模画布**：C 引擎准确实时预览与安全隔离、层级/锁定/多选、锚点、遮罩、可视网格与 UV/三角形编辑、参数/形态与双轴组合；验收为浏览器交互及 C 图像和几何对照。
- **角色素材与绑定**：自制可编辑层、遮挡补画、独立双臂/双手/发丝和口眼细件，头身接缝、参数极值、动态动作、物理逐项目视；少女长发戴帽袖手遮挡继续按隔离画稿→目视→用户确认→真实 C 帧→生产审批流程处理。
- **动作、物理与插件**：时间线、表情、声音/面捕映射、物理调试、插件 SDK、权限与崩溃隔离；本机动态库不是沙箱。按跨帧率、生命周期、安全和平台真机测试逐项验收。
- **发行与备份**：构建包、授权审计、Windows 真机、性能与成本限制的真实运行路径验证、恢复演练；每轮均提交并推送当前会话分支，记录结果。

## 研究参考

- Live2D 官方 [Warp Deformer](https://docs.live2d.com/en/cubism-editor-manual/making-and-placement-of-warp-deformer/)：控制点数与细节/计算负载取舍；其 Bézier 与转换分割是官方工作流，不等同本项目规则网格。
- Live2D 官方 [How to edit](https://docs.live2d.com/en/cubism-editor-manual/how-to-edit/)：拖动控制点及选择框交互的参考；未复制官方源码或使用私有 Core。
- 仓库 `src/core/zrig.c`、`src/core/zimg.c`：本项目 keyform 位移为部件素材像素，网格最终经绘制矩阵变换；真实输出以 C 为准。
