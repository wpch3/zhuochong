# 双形态隐藏画稿与接缝：连续工作流

## 铁律和范围

- 桌宠 Q、无兽 Chibi 与少女三个产品独立，比例、原图、参数和审批分开；不拿一套图拉伸充当另一套。保留黑描边和现有人设；鲸鱼发夹不是猫耳猫尾，未经确认不删除。
- 自研 zrig 只称 Live2D 风格的二维分层模型；不是 Cubism 的 CMO3/MOC3。官方格式和 SDK 需合法工具及许可。不得将平面 AI 图片自动切层或规则边缘延色谎称原始 PSD 或完整成品。
- 所有实验从记录来源的副本进行，拒绝覆盖源和既有试装。可编辑的分层画稿、烘焙补画及绑定分开保存；每次记下生成方法、输入指纹与参数。中立的静态像素对照不是 C 分层缩放后的等价证明。
- 每一轮目视原画、独立隐藏层、中立、两侧和组合姿态、浅深背景和局部；再用脑判断衣服结构、轮廓、遮挡先后、是否穿帮；差异像素和自动测试只辅助定位。未通过的版本不得提升为正式资源。
- 不以扩大动作、掩盖洞、过度收缩掩膜或单色涂抹换取数字过关；受限制的测试只对该模型、引擎、参数、比例和环境有效。建立更大摆幅前要有完整的肩袖、躯干背后和轮廓隐藏图。

## 长工作序列

1. 分别核对两种比例、图层、身体/肩袖与已知缺陷，查阅资料，制作并保存独立可编辑的隐藏服装画稿试验。视觉设计需跟随各自已有颜色、阴影和黑描边。
2. 建立可复现的烘焙和隔离验证：源哈希、坐标、Alpha、边距、图层次序与输出安全；先查看无遮挡底稿，再用真实 C 测中立、多比例、极值及中间态。允许试验失败，记录画稿缺陷。
3. Chibi：肩/袖/手的完整可编辑绘制与网格，独立眼白虹膜、眼睑、嘴、分离头发和物理；参数从小幅逐步扩展，不改变桌宠。
4. 少女：梳理已有的复杂肘关节、躯干和长发戴帽遮挡；对问题部位单独画稿、隔离绑定和真实 C 检查，不用 Chibi 几何代替。旧正式 rig 指纹和素材检测失败先定位，不靠重生成覆盖或放宽检查。
5. 工具和底层：支持真实分层源文件、可逆编辑、纹理图集、任意网格及双轴关键形态、遮罩同步、物理、项目依赖和插件隔离；建立性能基准、内存/边界测试与跨平台验收，优先服务已证实的模型缺口。
6. 验收与交付：源文件和许可证可追溯，工程往返、真实 C 稳定运行、动画组合与极值逐帧目视、用户确认、Windows 真机与发布回归；把阻塞项如实列出。每轮提交并推送当前分支。

参考：[官方插画处理](https://docs.live2d.com/en/cubism-editor-tutorials/psd/)（按动作拆分并补画隐藏部分），[素材分离](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/)，[Inochi2D 节点布局](https://docs.inochi2d.com/en/latest/creator/first-model/tutorial02.html)（层级和坐标）；本项目仅借鉴工作流程，不复制源码/素材或宣称格式兼容。
