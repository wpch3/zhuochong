桌宠 · 真机帧率测试
===================

这是干嘛的
----------
我的开发机只有 2 个 CPU 核心，测出来 848x1360 一帧要 33 毫秒（约 30fps）。
按并行效率外推，4 核应该到 17ms、8 核到 10ms —— 但那是**算出来的，不是量出来的**。
你的机器到底能不能让她跑满 60fps，只有在你电脑上跑一遍才知道。

这个程序就是去拿那个真数字的。它不会改动任何东西，跑完就退出。


怎么跑
------
1. 把整个「帧率测试」文件夹拷到你的 Windows 电脑上（哪里都行，桌面也可以）。
2. 双击里面的「帧率测试.exe」。
3. 等大概 1 分钟，会弹出一个黑色窗口刷一堆数字。
4. 跑完窗口里会停住，同目录会多出一个「帧率报告.txt」。
5. 把那个 txt 发给我就行。


跑之前最好
----------
- 把游戏、视频、浏览器大页面关掉。后台吃 CPU 会让结果偏低。
- 插着电源跑（笔记本用电池时 CPU 会自己降频，测出来不准）。
- 如果能跑两遍更好：一遍什么都不开，一遍开着你平时常开的东西。
  第二遍更接近她真正要工作的环境。


它测什么
--------
A. 线程伸缩   —— 1/2/4/8 个线程各要多少毫秒。这是我在沙箱里问不出来的问题。
B. 各尺寸档   —— 三种画面大小，分别统计：状态机、渲染、PNG 编码。
C. 持续 8 秒  —— 看抖动。平均快不代表看着顺，偶尔卡一下眼睛立刻能看出来。

报告里有一行「PNG 编码」—— 那一列**只有网页预览需要**。
真正的桌面版是直接把像素贴到窗口上的，没有这一步。
所以判定看的是「渲染」那一列，它才是桌宠真实的上限。


会不会有风险
------------
不会。它只读素材、在内存里画几百帧、写一个 txt。
不联网、不装驱动、不改注册表、不常驻。
杀毒软件如果报"未知发布者"，是因为这个 exe 没有花钱买代码签名证书，不是病毒。
