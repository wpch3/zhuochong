## 1. 性格参考（结论）

- 检索结果（百科、文章）显示，二次元性格标签有稳定的通用集合：傲娇、元气、毒舌、三无、温柔（姐姐）、天然呆、腹黑、病娇、电波、女王。
- 这些是**标签级参考**，不是具体角色。直接照搬某个角色的台词或形象会有版权风险，因此只取标签，再做原创设定。
- 视频网站上具体角色的流行设定我这次没有逐个核对，不能保证它们的热度和授权情况。
- 处理方式：每个 AI 角色选 1–2 个标签作为骨架，再按桌宠的使用体验（陪伴、不打扰、有反差、台词短）做二次元化改写。
- 草稿映射（待确认）：深语=腹黑/毒舌理性；拂晓=温柔姐姐；星璇=元气；双晞=天然呆与腹黑交替；通琳=邻家温柔；月见=三无/文静；闪电=傲娇。小寻=元气+傲娇（已有草稿）。
- 需要用户确认：是否接受这种“标签 → 原创二次元化”的做法。

## 3. 接入设计（待确认后实现）

- **统一接口**：保留现有 `kind: openai_compatible` 的对话接口，新增 `tts` 段。中转站和官方直连用同一份配置格式，只是 `base_url` 与 key 环境变量名不同。
- **中转测试**：中转站 base_url 与 key 由用户在 Arena 环境变量中配置（变量名约定 `ZC_RELAY_BASE_URL`、`ZC_RELAY_KEY`），不在仓库和聊天里写明。需要确认中转是否支持语音合成接口（OpenAI 兼容的 `/audio/speech`，或供应商原生接口）。
- **每句都出声**：台词按句出声，用流式或分句合成，减少首句延迟。出声与文字气泡同时出现。
- **自定义开关（默认关）**：
  - `voice.output.enabled`：总开关，默认 false。
  - `voice.output.per_line`：是否每句出声；关闭时只显示文字。
  - `voice.output.daily_char_limit`：每日字符上限，超出自动退回文字，防止浪费额度。
  - `voice.call.enabled`：语音通话回应开关，独立于台词出声。
- **供应商兼容**：`providers.json` 每个供应商声明 `chat`、`tts` 能力，缺哪个能力就自动关闭哪个功能并给出字段级诊断。
- **测试**：单元测试用假 TTS 服务（不联网）验证开关、额度、降级；真实中转测试标记 [沙箱实测]（需 key）；扬声器与播放在 Windows 上标记 [需真机]。
