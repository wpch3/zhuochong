# 优先 Chibi：真实底稿与动作的连续工作包

桌宠、少女及已有试装不覆盖。用户优先完成 Chibi，先聚焦无兽黑描边试装的袖手、衣身和底稿；本项目 zrig 为自研分层 2D，不是官方 Cubism 格式。

## 顺序和验收

1. 再次目视全图、拆分、无遮挡底稿和 ±2° 极值；对照 [Live2D 素材拆分](https://docs.live2d.com/en/cubism-editor-tutorials/psd/)及 [Clip Studio 隐藏补画](https://tips.clip-studio.com/en-us/articles/674)，明确完整肩袖、前臂、手、衣身及重叠区域需分别构图。不要用有限像素差当作原画。
2. 在中立手臂下方制作独立、可编辑的衣身侧面底稿：撤除旧的横向拉伸条，再建立连续布形、褶皱、阴影和必要重叠。来源、参数与构建可追溯，完整矢量底稿和烘焙 PNG 均保留；不能覆盖现有模型。
3. 将试验候选用真实 C 逐比例、逐姿态和循环运行，分别看无遮挡底稿与正常动作下的浅/深背景及放大边缘。若底稿影响本不该动的区域、接缝不顺、出现多余轮廓、漂浮或静止漏色，明确拒绝，不放宽验收。
4. 验证动态控制、物理回稳、浏览器交互、源码与工程往返，核实新的生成器输入锁定与不覆盖；失败需要定位，不伪称生产完成。
5. 隐藏原画与关节视觉满意后才能扩大动作，再依次完善上臂/前臂/手、瞳孔/眼白/眼睑/口腔、网格、遮罩、物理和动作组合；逐项测试且目视。需要艺术重绘的工作保留未完成状态，不将静止或少数帧冒充合格成品。

## 本轮实作和检查

独立绘制两版 SVG 衣身侧片，撤去旧程序延色条，从原图切片和袖手重新组装隔离候选。第一版肩边在深底外露，调整后明显收敛；但第二版无遮挡衣身仍缺乏完整结构，袖侧接缝及缩放中立帧差异未消除，未批准进入正式模型。AI 去袖结果只有白底平图、无可靠隐藏分层，未采用其像素。

第二版经过真实 C 多尺度固定步进（双基线复测一致后再对照）、参数/循环/物理、真实 Chromium 滑动/复位、`.zproj` 12 文件往返及重新载入 C 帧比较。上述范围内工具链通过，不代表所有插件、模型功能、环境或视觉质量通过。命令、具体结果和未完成项见 `experiments/live2d_chibi_underlay_art/README.md`。
