# 任务模板区规划（P1.6）

更新：2026-10-24。本文件规划给用户复用的工作流模板库；它与 `docs/TASK_TEMPLATE.md`（开发团队每项工程任务的规格模板）用途不同。这里设计的是产品内“用户一键建立任务”的模板，不代表模板运行器或模板市场已实现。

## 1. 两种“模板”必须区分

- **工程任务规格模板**：供开发/代理建立清楚的任务定义，见 `docs/TASK_TEMPLATE.md`。
- **产品内工作流模板**：供用户保存输入表单、步骤图、工具/Skills选项、输出位置、确认点和验收规则，供后续复跑/复制。

两者不能共用同一种执行权限：模板只描述请求，不保存授权令牌，不绕过每次运行的权限校验。

## 2. WorkflowTemplate 数据结构（概念）

字段候选：
- ID、名称、说明、模板版本、作者/来源、创建时间、适用应用版本、许可证；
- 输入表单：字段 ID/类型/验证/默认值/敏感级别/必填状态；
- 步骤 DAG：步骤目的、依赖、类型（对话/生成/代码/人工检查）、工具/Skill allowlist、输入输出 schema；
- 权限需求声明：文件目录/网络主机/模型供应商/设备/外部账号，不含实际授权凭证；
- 预算和限制：预估成本/硬上限、时长、并发、重试次数、最大步骤；
- 人工检查点：运行前计划确认、数据外发确认、diff审核、结果质检、发布确认；
- 产物规则：目标类型/目录占位符、命名、版本覆盖策略、来源/许可元数据；
- 完成定义：可检查的条件、测试要求、输出清单；
- 失败恢复：哪些步骤可重试/继续、是否有副作用、回滚路径。

模板仅保存变量占位符和配置值；运行历史/秘密/个人内容不能写回公共模板。

## 3. 模板生命周期

`browse → inspect → copy_or_select → fill_inputs → validate → preview_plan_and_permissions → approve_run → execute → review_outputs → save_as_new_version_or_delete`

- 选模板后生成一次性的 run 副本，冻结模板版本、应用版本、参数和权限快照，避免运行中变更。
- 用户输入敏感字段时标记仅本次使用，不自动保存到模板；密码/API Key 不得进入模板。
- 执行计划和需要的权限应在运行前可读；未授权能力应提示缺少授权，不可悄悄跳步骤或改成外发路径。
- 修改模板产生新版本；旧运行仍引用原模板版本，不被更改。
- 复制/分享/导入前扫描个人数据、密钥、绝对路径和专属账号；默认仅本机保存，不建立远端模板市场。

## 4. 模板分类与首批候选

- **对话与资料**：带来源的研究摘要、文档大纲、翻译/校对；检索/引用策略可选。
- **生成**：生图参考板、文字草稿、音频合成、视频分镜；每类有独立输入和产物检查。
- **代码**：只读代码审查、缺陷定位/修复、测试与构建；按 `CODE_WORKSPACE_PLAN.md` 审批；不得默认启用 commit/push。
- **素材制作**：REF-FIRST 角色素材计划、透明/分辨率检查、拼合预览；不将程序绘制当作原画产物。
- **维护**：本地备份、更新检查、项目健康诊断；任何删除/更新/网络操作需单独确认。

首批模板数量不为“看起来丰富”而凑；先选用户真实高频且边界清楚的 3–5 个，需原型/用户使用反馈后决定。上述仅是候选类别。

## 5. 模板来源与安全

- 来源标记为内置、用户创建、导入第三方；第三方模板显式显示作者、许可证、版本和步骤。
- 模板不能直接装载代码或 Skill；每个 Skill/工具引用须在 Skills/代理区验证存在并有本次授权。
- 模板中的自然语言提示与网页/文件内容都视为不可信数据，不能改变系统策略。
- 运行执行端重验路径、预算、权限、工具schema、模型供应商能力和依赖版本；模板被篡改/签名不符时拒绝运行。
- 导入模板按数据文件解析，禁止反序列化执行代码；未知字段拒绝或隔离，不静默忽略危险字段。

## 6. 编辑器与运行体验

- 模板浏览页：分类/搜索/用途、适用限制、权限标签、更新时间和信任来源。
- 详情页：步骤图、输入清单、权限和成本说明、产物形式、删除/分享范围。
- 编辑器：字段表单 + 可读步骤列表/DAG；低代码编辑优先，复杂结构可在高级模式查看；更改可预览差异。
- 运行前：显示本次输入、模型/供应商、路径、权限、预算、预计副作用和用户确认点。
- 运行中：将每一步映射到统一任务队列；可暂停/取消；同一模板可并行多少次由任务预算和写入目标决定。
- 运行后：逐条验收、产物预览、保留/删除选项、失败/重试说明；可“另存为新模板”，默认不覆盖原模板。

## 7. P1.6 验收拆分

**规划验收（本次完成到文档层）**：明确与工程任务规格模板区分、schema/版本、运行前预览、权限再校验、模板版本冻结、敏感字段规则和失败恢复。

**实现验收（尚未开始）**：恶意导入字段拒绝、路径/Key 清理、权限扩张检测、模板版本冻结、运行计划变更需确认、并发冲突、导入导出安全、删除/复制语义、旧 run 可复现、技能不可被模板绕过权限。

**用户评审**：确认首批 3–5 个高频模板的真实性、模板详情能否看懂所需权限与成本、编辑和撤销是否易用；未评审前不创建远程市场或公开分享功能。
