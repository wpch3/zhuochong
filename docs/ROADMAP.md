11. **T47** —— **物理底座 2.0**（用户 2026-10-17：「目前还没有真实的物理效果…物理效果的底层做好没有？」）。
    盘点写在 `docs/PHYSICS_PLAN.md`：**做对的是难的那一半**（固定步长积分 + 输入插值 + 帧间插值 +
    多段链 + 参数输入，都照官方 `CubismPhysics::Evaluate`），**缺的是像不像的那一半** ——
    我们的摆是 1D 弹簧、输出「滞后像素」，官方是 **2D 粒子链、输出「相对重力方向的摆角」**。
    - **一句话症状**：输入不动 ⇒ 输出恒为 0 ⇒ **静止时头发、尾巴、裙子全是死的**
      （挂件表里实测记着：呼吸 0.28Hz 下尾巴只摆 **0.3 px**），现在的"自主摇晃"都是 motion 在演。
    - 顺序：**T47.1 粒子内核 → T47.2 输出适配 → T47.3 重力与风** 是地基（M1/M2），
      之后 T47.4 惯性（拖窗口要甩头发，这条官方和 BongoCat/VPet 都没有）、T47.5 `physics3.json` 互通、
      T47.6 布料多链、T47.7 软碰撞、T47.8 性能护栏（**和 T30 高分辨率绑在一起做**）。
    - 验收判据里最硬的一条：**冻结输入静置 10 秒，发梢仍要有 ≥2 px 的自主摆动**。
    - ★ **T47.1 粒子内核 2026-10-17 晚已交付**（`src/core/zphys2.{h,c}`）：和 Python 参考实现
      跑 600 步**逐步对拍 < 1e-6**（动 1% 空气阻力就红）；实测输入归零后发梢仍摆
      **40.9°→2.6°**（衰减中，旧内核恒 0）、只剩呼吸时仍有 **1.00°**（旧内核 0.3px≈不动）。
      **但摆角还没接到部件上**（`rig.json` 一字节未改）—— 那是 T47.2，做完才看得见。
    - ★★ **T47.2 输出适配 2026-10-17 晚已交付 —— 现在画面上看得见了**：长发 3 粒子 +
      呆毛 2 粒子两条链接到真部件（`bend_x` + 两个网格形变器），teen / chibi 两形态都有。
      实测**手停在屏幕中央不动、3.5 秒里发梢自己走完 +16px → −26px → 回 0**
      （留证 `logs/asset_qa/t47_2_hair.png` 七连拍）；转头像素行程 32px vs 旧内核 28px（1.14×，同量级）。
      踩到的真问题：像素空间没有官方 `Normalization` 那层 ±10 的上限，一帧瞬跳会让摆**过顶转圈**
      （实测 179°），解法是在适配层限幅（DC78），不污染内核。
    - ★★ **T47.3 重力与风 2026-10-18 已交付**：风三路相加（定常 + 常驻微风 + 阵风），
      调试端点 `/api/force`，rig 里新增 `forces` 段。**顺手逮到一个跨两次交付的老 bug**：
      摆角读数是反号的（像素空间 Y 轴向下，`atan2` 的有号角被镜像），
      画面上就是"风往右吹、头发往左飘"——855 条断言全写了 `fabs()` 所以一条都没拦住
      （DC79 / LESSONS 206）。修完实测：风 +0.3 吹开 40.9px 方向正确、
      风停 2.5 秒收敛、阵风 37.2px → 3 秒 4.6px，留证 `logs/asset_qa/t47_3_wind.png`。
      ★ 这一步做完，**尾巴/耳朵的"常驻微动"就可以从 motion 通道退役了**（T50.4 的前置）。
