## ⏳ 第三步：功能（按用户"之后还有很多"）
1. Web 主工作区：流式对话、本机 API 网关（Key 只存本机）、Token 计量与费用记录。
2. 语音：适配层（STT / TTS / 实时双向 + 打断），供应商可切换（参考 airi 的四段结构）。
3. 实时配音：回复语音与文字同步、口型跟随（AEIOU）。
4. 社交（每项独立开关，默认全关）：群聊、循环回答、朋友圈、双角色召唤、请求打电话。
5. 生成分区：生图 / 生文 / 生视频 / 生音频 / 生代码。
6. 全局键鼠反应（可选，需授权）。

## ⏳ 第四步：打磨
道具托盘、话题卡片、Token 心形进度、加载态用角色小动作、托盘菜单美化、
护眼色与无障碍、安装包与自动更新。
