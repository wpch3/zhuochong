# 语音表现力规划：语感（情绪/语气）与萌系少女音色

> **起因（2026-10-17，用户原话，不许改口径）**
> 1. 「语音的情绪变化、语气等我听测试台词都**没有变化**，要做出**真人的语感**」
> 2. 「小寻的声音要**更像少女**一点，现在的测试台词的音色**更像青年**」
> 3. （试听我给的两个外部真人音源后）「**两个都不对，又回到那种真人的粤语了**，
>    要**动漫二次元美少女的音色**」
> 4. 「你的这个语音你都不记得了吗？**截图里你自己做的**，只不过声音要**更萌更有情感**」
> 5. 「记得**查教程和资料**，要做的更精细一点」
>
> **第 3、4 句是转折点**：路线从"再去找一个更好听的外部音源"收敛为
> **"把我们自己这套 edge-tts 晓伊调得更萌、更有情感"**。外部真人音源这条线**作废**。
>
> **一句话结论：不是音色不够萌，是她在念稿。**
> 先修韵律基本盘，再谈情绪；先把免费通道榨干，再谈换引擎。

相关文件：`config/prosody.json`（语感表）、`tools/voice_prosody.py`（演出引擎）、
`tools/voice_render.py`（渲染）、`characters/xiaoxun/voice/plan.json`（角色接线）、
`docs/VOICE_PLAN.md`（更早的语音总规划，仍有效）、`docs/REFERENCE_NOTES.md` 第四十二批（资料出处）。

## 1. 诊断：为什么"听不出变化"——三层根因，一层比一层致命

| 层 | 现状 | 后果 |
|---|---|---|
| **① 通道** | teen 首选 `mm_shaonv`（MiniMax 少女音）**没有密钥**，实际全部落到回退链末端的 `edge_tts + zh-CN-XiaoyiNeural`。而 **edge-tts（免费通道）不支持 SSML 的 `mstts:express-as`**，情感标签会被整条忽略 | `config/emotion_map.json` 里 `fallback_order = ["style","emotion","tag","prosody"]`，**永远落到最后一档 prosody**。情绪在这条通道上**结构性做不出来** |
| **② 参数** | `plan.json` 的 style 是 `+0% / +0Hz / +0%`，候选音色表里那些升调档**从来没启用过** | 音色停在晓伊出厂设定。公开音色表把 `zh-CN-XiaoyiNeural` 标注为「女 / **青年** / 活泼」—— **用户"像青年"的判断和官方标注完全一致，不是错觉** |
| **③ 方法** | `voice_render.py` 对一条台词只调用一次合成，给**整句一个** rate/pitch/volume，没有停顿控制、没有重音、没有句内变速 | 一句话从头到尾是一条直线。业界把这个症状直接叫**"念稿感"**，病根是「语速恒定 + 停顿只认标点 + 不分轻重 + 语调套模板」 |

**所以"情绪没变化"不是没调参数，是这条链路上根本没有能承载情绪的位置。**

## 2. 查到的资料（结论版；URL 全部写在 `docs/REFERENCE_NOTES.md` 第四十二批）

1. **Azure `mstts:express-as`**：`style` + `styledegree(0.01~2)` + `role`。
   - **style 写错或该音色不支持 ⇒ 整个元素被忽略、退回中性**（很多人"加了没反应"就是这个）。
   - `zh-CN-XiaoyiNeural` 有 9 种 style：affectionate / angry / cheerful / disgruntled /
     embarrassed / fearful / gentle / sad / serious。
   - **`role`（Girl、YoungAdultFemale…）只有晓墨 / 晓萱两个音色支持，晓伊用不了** ——
     想靠 `role="Girl"` 直接变少女，这条路在晓伊上是堵死的。
2. **Azure Dragon HD**：`zh-CN-Xiaoyi:DragonHDFlashLatestNeural` 支持
   **cute / shy** / gentle / nervous / complaining / angry / sad / strict，
   外加副语言标记（laughter / breathing / sighing / yawning…）。
   **cute 与 shy 正是"二次元萌系"最需要的两种**，这是中期最高性价比的一跳。
3. **edge-tts 对照**：Edge TTS **没有情感风格，只有 prosody**；Azure 才有 10+ style。
   ⇒ 在不换通道的前提下，**唯一的出路是把 prosody 用到极致**。
4. **韵律四要素**：节奏 / 停顿 / 重音 / 语调。
   **反面警告也一起抄下来**：过度表演是另一种不像人；
   大部分句子应接近中性只带底色；**情绪与语义错位比平淡更糟**。
5. **停顿量化**：短语停顿 120~300ms、戏剧停顿 400~700ms、模拟吸气 150~250ms，
   **每 8~12 个词换一次气**；全局 `rate` 保持 0.9~1.1，
   **强调靠局部降速到 80~90%，不要全局加速**。
6. **少女音的声学**：**F0 和共振峰必须一起移**，只动一个改不了年龄感
   （只升 F0 = 花栗鼠，只动共振峰 = 怪腔）。
   成年女性 F0 约 165~255Hz，10.5~14.5 岁女孩约 213Hz；
   音色配方：**削 200~500Hz 的胸腔共鸣、提 3k~8kHz 的空气感、尾音带甜**。
7. **2026 年开源情感 TTS**：**IndexTTS2**（Apache-2.0，1.5B，音色与情感**解耦**，
   8 维情感向量 + `emo_alpha` 强度旋钮）、**CosyVoice2-0.5B**（Apache-2.0，自然语言指令控语气，
   首包 ~1.5s）。⚠️ **IndexTTS-2.5 改成了 Bilibili Model License，不再是 Apache** ——
   要用就钉死在 2.0 版本。

## 3. 已落地：演出单（Performance Sheet）

### 3.1 结构

```
台词 id + 文本
      │
      ├─ ① 判情绪   id 精确命中 > id 前缀命中 > 文本线索（语气词/标点/关键词）
      │
      ├─ ② 切段     按标点切，长句按"每 11 字换一次气"再切；最多 8 段
      │
      ├─ ③ 排演出   每段给出 语速% / 音高Hz / 音量% / 段后停顿ms / 标注
      │              = 语感档(moe_shoujo) + 情绪偏移 + 位置修饰(起势/句尾上扬/拖长/重音)
      │
      └─ ④ 出三种格式
             to_edge()    → 逐段参数，给 edge-tts 分段合成后拼接（现在用）
             to_ssml()    → <mstts:express-as style=… styledegree=…> + prosody + break（Azure 一到位就能用）
             to_minimax() → emotion + speed/pitch/vol（MiniMax 一有密钥就能用）
```

**一份语感表，三条通道共用** —— 以后换引擎不用重写演出逻辑。

### 3.2 `moe_shoujo`（萌系少女档）干了什么

| 手段 | 值 | 为什么 |
|---|---|---|
| 整体偏快偏高 | rate +6% / pitch +18Hz | 年龄感主要来自 F0 与语速，这是"更像少女"的主力 |
| **句尾上扬** | 末段 +6Hz | 日系萌音的标志性特征；中性句也带一点，避免陈述句下沉显老 |
| **语气词拖长** | 「呀/啦/哦/呢/嘛/吧/喵」所在段降速 12% | 拖长的是语气词，不是整句——整句慢就变成困倦了 |
| **重音** | 「别/不要/最/超/真的/好…」所在段 +8% 音量 | 重音只给一个词，全句加重 = 吼 |
| **换气** | 每 11 字插 180ms | 对应资料里的"每 8~12 词换一次气"（中文按字折算） |
| 停顿表 | ，220 / 。320 / ？280 / ！240 / …420 / ——300 ms | 落在"短语停顿 120~300ms"区间内 |

### 3.3 情绪表（11 种）

neutral / happy / smile / shy / angry / pout / sad / surprised / gentle / sleepy / proud，
每种给 `rate / pitch / volume / pause_scale / style_degree / end_rise_bonus` 六个相对偏移。
实际排出来是这样（同一句话）：

```
--- neutral ---  今天也一起加油吧，  -6% +18Hz  停220ms      我陪着你。  +2% +24Hz
--- happy ---    今天也一起加油吧，  +4% +32Hz  停187ms      我陪着你。 +12% +46Hz
--- angry ---    今天也一起加油吧，  +8% +28Hz 大声 停154ms  我陪着你。 +16% +34Hz
--- sleepy ---   今天也一起加油吧， -24% +12Hz 小声 停396ms  我陪着你。 -16% +14Hz
```

### 3.4 两道"别演过头"的闸（资料里的反面警告落成代码）

- **克制上限**：任何一段 `|rate| ≤ 26%`、`|pitch| ≤ 46Hz`；
  **一个角色的台词里强情绪（angry/surprised/sad…）占比不得超过 45%** ——
  超了就说明情绪判得太随意，整批都会变成浮夸。
- **负向对照**（`--selftest` 第 6 项）：把情绪表人为调平后，
  自检**必须报"分不出来"**。否则说明这道闸是空转的
  （本仓吃过亏：白名单字段写了没人读 = 闸门空转）。

### 3.5 渲染管线

逐段合成 → 段间插静音 → 拼回一条 mp3（有 ffmpeg 走 `concat` 重编码，没有就二进制兜底）。
**任何一段失败，整句退回"老的一次合成"**（宁可平，不可缺）。
`catalog.json` 为每条台词记下 `emotion` / `emotion_why` / 逐段参数 —— 能回答"这句为什么这么念"。

## 4. 音色：从"青年"挪到"二次元少女"的三条路

| 路线 | 做法 | 代价 | 能到哪 |
|---|---|---|---|
| **A（现在就能用）** | edge-tts 晓伊 + **升调 15~45Hz** + 本语感档 | 0 元、0 密钥 | 年龄感明显下移、句子有起伏。**但音色底子仍是"活泼青年女声"，到不了标准二次元萌音** |
| **B（中期，最划算）** | **Azure Dragon HD 晓伊的 `cute` / `shy` style** 或 **MiniMax 少女音** | 要密钥、按量计费 | 真正的"萌"与"害羞"音色，副语言标记还能加呼吸/轻笑。`to_ssml()` / `to_minimax()` 已经写好，**填密钥即生效** |
| **C（终局，离线）** | 本地 **IndexTTS2**（情感向量 + 强度旋钮，音色情感解耦）或 **CosyVoice2** | ~4~8GB 显存、要部署 | 音色与情感彻底可控，离线可用，符合"本地模型区块"的既定方向（A18/DC18） |

**走 A 的两条纪律**：

1. **年龄感优先用引擎自带的 pitch 参数**（模型内部重新合成，共振峰自洽），
   **不要上来就用后处理移调**——纯移调只动 F0 不动共振峰，必然"花栗鼠"。
   `tools/voice_pitch.py :: youthify()` 已经是正确做法（重采样同抬 F0 + 共振峰，再用相位声码器拉回时长），
   但它只作**兜底**与**离线微调**，不进默认链路。（→ DC74）
2. **升调有天花板**：候选表一路给到 +45Hz 是为了让用户**听到失真的边界在哪**，
   不是推荐值。默认取 +25Hz，由用户耳朵定档。

## 5. 验收口径（"能听出来"才算做完）

1. **盲听对照**：`characters/xiaoxun/voice/demo/` 下同一句话 × 六种情绪
   （neutral / happy / shy / angry / sad / sleepy），**不看文件名**随机播放，
   用户能把其中至少 **4 种**对上标签 ⇒ 情绪这关过。
2. **音色选档**：`characters/xiaoxun/voice/samples/` 下 10 个候选，
   用户指定一个作为小寻的正式音色 ⇒ 年龄感这关过。
3. **量化**（沙箱可自测，不依赖人耳）：
   - 同一句不同情绪之间，**逐段参数不得完全相同**（自检第 2 项）；
   - 多段句**至少有两种不同参数**（自检第 3 项，防"分了段但都一样"）；
   - 切段拼回去必须**和原文一字不差**（自检第 1 项，防吞字）；
   - 选定音色后用 `voice_pitch.py --measure` 量 F0 中位数，**目标 200~260Hz**。
4. **闸**：`tools/voice_prosody.py --selftest` 7 项全过，并接进 `selfcheck_repo.py` 与 CI。

## 7. 明确不做

- **不做过度表演**。资料里的反面警告直接落成硬上限（§3.4），
  宁可"大部分句子接近中性只带底色"，也不要每句都在演。
- **不再找"真人感"的外部音源**（用户 2026-10-17 已明确否掉两个候选：
  「又回到那种真人的粤语了」）。目标是**动漫二次元**，不是录音棚真人。
- **不接豆包**（DC13，用户 2026-10-14 原话"绝对不要豆包"）。
- **不做零样本克隆别人的声音**（I6 合规线）：只用官方音色 + 情感控制，
  或自有/授权音源。
