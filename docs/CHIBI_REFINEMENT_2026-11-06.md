# Chibi 手口眼和关节重绘：合并试验

状态：**独立候选，未通过美术验收**。自研 zrig 与 C 引擎，不是官方 Cubism。没有覆盖正式 Chibi、少女或桌宠。前一轮的手口与眼睑是分开的试验；这次在新的构建目录中合并后再次检查。可编辑 SVG 和实际 C 截图保存在 `experiments/live2d_chibi_refinement/`。截图是目视记录，数字只验证运动和复现，不代表艺术质量。

## 重画与绑定

1. `fingers.svg` 将前稿五指的闭合轮廓改成只在自由边描线，根部埋进新掌心，延长食指根连接；圆化拇指，十指仍独立绑定并继承腕关节。左右目前仍是镜像，不是两张完成的手形画稿。
2. `wrist_underpaint.svg` 给手背补画藏在袖下的延续，袖口绘制在手掌前面。实看袖口源片发现小黑钩是袖部切分时保留下来的暗色边，并非单纯的皮肤噪点；本稿在两端指定的小范围与原切线外删除袖口尖刺。原袖/手没有被覆盖，但此候选中立像素不再与旧稿相同。
3. `shoulder_underpaint.svg` 重画圆形青色肩部延续；`jacket_sides.svg` 重画外套的隐藏侧片，叠在原始身体切片下。肩底仍限制在中立时原袖或身体不透明区，不能把它当作完整肩袖原画。不同角度侧片仍存在细条和边缘不连续。
4. `mouth.svg` 使用**同一条上唇线**从闭合变形到张开，不再交叉淡化两条不同闭嘴线；口腔、舌、牙光及下唇仍分层，下唇在开口约 0.2 后才淡入。新笑线改变旧闭嘴外观；口角、网格采样和完整音素仍需继续制作。
5. `eyelids.svg` 稍减薄睫毛，清理旧合图中残留的眼底及侧边碎片，眼白/虹膜在接近全闭时渐隐；眼睑行程从 38 改到 44，使其更贴近遮罩下沿。眼睑最后四分之一开度有少量网格形变。较强的网格方案导致闭眼变成双峰波浪，已拒绝，留 `qa/blink_mesh_rejected.png`。引擎内建眼开合参数自动存在，不能重复声明，否则 C 加载失败；实验关键形态直接引用内建参数。当前闭眼仍呈厚拱形，不是自然闭眼线。
6. 本候选融合眼白、虹膜、眼睑、口腔及十指；预览增加视线和手指控件。原有 `wrist_report.json`、`joint_report.json`、`binding_report.json` 记录上游候选，不描述新图，构建器标记它们已被 `refinement_report.json` 覆盖。

## 真实画面观察

`qa/neutral_full.png` 是 1.0 比例全身，`hand_*.png` 是左右手及腕/指极值，`mouth_*` 是 0、0.05、0.1、0.25、0.5、1，`blink_*` 与 `wink_left_light.png` 是睁眼、半眨、近闭、全闭与单眼；组合及深底多比例截图也已保存。

- 新指根与掌的外轮廓较连续，拇指不再是原来的尖角，袖口尖刺在检查帧减少；但手指仍像平行细条，极值处有交叠，仍需非镜像手型、关节结构、指间遮挡和运动绘画。
- 小开度不再看到两条独立闭嘴轮廓，0.1 是上唇线加浅口腔，0.25 已张开；嘴角仍有小钩/淡边，张大时上沿形变略硬。没有完成 A/I/U/E/O 的独立口型。
- 睫毛下方的固定旧残线和完全闭眼的白线已减少；近闭 0.92 仍见一条细灰蓝亮边，闭眼睫毛厚且形状像拱门，整体移动感明显；重绘眼睛与原貌不同，表情专用眼睑和复杂头发遮挡未完成。单眼闭合可见，但未证明所有表情组合正常；眼睑关键形态取引擎内建开合读数，表情叠加时与实际遮罩的一致性仍需专门复核。
- 深色背景、0.35/0.55/0.8/1.0 的双臂中立/内外摆，以及肩肘腕指组合有截图；侧身边缘、袖口缩放及关节大角度仍需逐帧检查。不能因小角度不穿帮就说肩腕接缝已完全解决。

采集 `metrics.json` 中十指单动为 87～176 像素；口部全开/闭 817、半眨 4261、全闭 6962、单眼闭合 3422、左右视线 2726；循环两个取样 1007。数值依赖位置、比例与抓帧，不能代替肉眼。`ParamEyeLOpen` 的单眼检查与重置要在 `blink=0` 时进行；`/api/param?all=1` 会释放手动眨眼，重置后必须重新设定，避免把自动眨眼误认作视线差异。

## 重建与测试

依赖 Pillow、numpy、resvg-py 0.5.0，C 预览先 `make build/zhuochong_preview`。所有输出必须是 `build/` 下尚不存在的新目录：

```sh
python tools/build_chibi_refinement.py build/chibi-refinement-repro
python tools/capture_chibi_refinement.py build/chibi-refinement-repro build/chibi-refinement-repro-qa
python tools/preview_live2d_chibi.py --dynamic --dynamic-study build/chibi-refinement-repro --preview-root build/chibi-refinement-repro-preview 5247
make test-chibi-refinement
node tests/test_dynamic_study_ui.js
```

真实 Chromium 可运行 `tests/test_chibi_refinement_browser.js`，其默认连接 5247，可用 `ZREFINEMENT_PREVIEW` 指定地址。预览服务没有身份认证，仅用于沙箱，不放真实密钥或私人数据。

本轮构建隔离/路径保护、十指逐项、嘴/眼/单眼/视线和组合、手指循环、A 音素驱动开口、41 文件 `.zproj` 验证解包及 C 帧往返通过；Chromium 的指/肘/视线滑块、复位、循环按钮通过。肩肘、手腕、衣身、动态、绑定器、项目包和动作 API 回归通过；完整 C 测试 2646 通过、0 失败，示例模块热加载和长稳未执行。旧正式 Chibi 仍有 3 条加载警告；未做 Windows 真机验证。
