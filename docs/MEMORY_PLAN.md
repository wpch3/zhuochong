# 分层记忆与个性化规划（P1.8）

更新：2026-10-24。本计划定义用户可控的对话/项目记忆，不代表向量库、RAG、跨会话记忆或自动记录功能已实现。记忆优先是可检查的本地数据管理问题，其次才是检索技术选择。

## 1. 记忆层级

| 层级 | 内容 | 建议寿命 | 默认行为 |
| --- | --- | --- | --- |
| 当前输入/轮次 | 当前用户消息、当前模型回答、正在处理的临时上下文 | 当前轮次/任务 | 处理后按会话设置处理；不自动成为长期记忆 |
| 会话记忆 | 当前对话的有限历史/摘要 | 当前会话；用户可清空 | 明确会话边界；不跨会话串用 |
| 项目记忆 | 用户批准的项目目标、路径约定、设计决定、已验证事实 | 项目生命周期/用户设置期限 | 项目隔离；来源可追溯；切项目不自动携带 |
| 用户偏好/长期记忆 | 语言、输出格式、明确要求记住的偏好/事实 | 仅用户批准并可设过期 | 建议先询问；敏感内容不默认保存 |
| 可检索资料库 | 用户选择导入的本地文档/素材说明/项目文档 | 用户管理 | 只索引明确选定内容；保留文件来源与删除映射 |

与程序内不可变安全规则、角色设定或任务配置区分：它们不是从对话推断出的记忆，不能让用户记忆覆盖权限、安全策略或当前指示。

## 2. 记忆条目结构

每条记忆概念上包含：`memory_id`、类型、内容/受保护引用、来源（会话/文件/用户输入）、创建/更新时间、有效期限、置信度/确定性、敏感级别、适用范围（用户/项目/代理）、用户批准状态、是否从摘要派生、引用父条目、删除/纠错状态。

- 区分明确陈述、系统观察、模型推断和用户批准的总结；推断不能伪装成事实。
- 单条记忆可查看原始依据或摘要依据；检索结果可供用户核对。
- 相互矛盾、过期、来源不明或低置信记忆应谨慎使用或询问，不能默默覆盖用户当前说明。
- 同一事实在多层记忆中重复时建立引用/索引，而不是复制无法同步删除的多份正文。

## 3. 写入、检索与遗忘

### 写入
- 默认仅保存当前会话实现多轮连续性；长期记忆采用“建议—预览—用户接受”或显式开关。
- 仅写入稳定、有未来价值、非敏感、来源清楚的项目约定/偏好；原始聊天全文不自动变成用户档案。
- 提供“不要记住此内容”与“记住这条”的直达操作；用户可关闭长期记忆而不影响当前轮次对话。

### 检索
- 先按范围/权限/时间过滤，再按相关度检索；禁止跨用户、跨项目、跨代理越界。
- 输入模型前显示或记录使用了哪些记忆来源（本地可查看）；敏感项单独授权。
- 记忆仅为证据之一；当前明确指示优先于旧偏好；关键决策以用户确认记录为准。
- 无相关可信记忆时返回未找到，不编造“我记得”。

### 更新/删除
- 用户可查看、编辑、设过期、删除、导出单条/某层/全部；记忆关闭时说明是否仍保留会话日志。
- 删除必须清理正文、派生摘要、搜索索引、向量/关键词索引、缓存与代理checkpoint的引用；备份中明确最晚清除时机。
- 用户改正某条记忆后保留更正来源，旧事实不可再次作为有效上下文。
- 对供应商已收到的上下文，明确本地删除不能代替供应商侧数据删除申请。

## 4. 隐私与权限

- 长期记忆默认关闭或逐条确认，具体默认由用户决定；当前规划不擅自设为默认开启。
- 敏感类别（健康、财务、身份/凭证、精确位置、私人关系、未成年人信息等）默认不做长期记忆；若产品需支持，应单独设计更严格授权与保留策略。
- 记忆数据本地加密/安全存储需求在实现前评估；API Key/密码/身份认证秘密绝不存入AI记忆。
- 记忆显示、检索、导出和删除均纳入权限审计；日志不含记忆正文。
- 云端推理仅发送完成当前任务所需上下文；先展示供应商与记忆来源，遵从 `PRIVACY_PERMISSIONS_PLAN.md`。

## 5. 与代理/Skills/任务模板的隔离

- 每个项目和agent profile可有独立记忆命名空间；跨命名空间共享须显式授权并记录来源。
- Skills 默认不能读取长期记忆；每次调用仅给其完成功能所需的最小摘要。
- 任务模板不保存记忆正文、Key、账户信息或个人目录绝对路径；模板运行时由用户重新提供或选择。
- 代理恢复任务使用checkpoint而非长期记忆；恢复前重验权限、预算、文件变化和副作用，不能因为记忆里“上次同意”就重复执行。

## 6. 实现路线候选

- 首先实现用户可读的本地结构化记忆列表、范围/来源/删除；
- 再选简单关键词/标签/全文索引，测量是否够用；
- 仅在数据规模和召回评测证明有必要后，评估向量检索/RAG及其本地索引、嵌入供应商、删除与隐私成本；
- 不先承诺特定向量数据库，也不照抄 Neuro-sama 未公开的记忆实现。

## 7. P1.8 验收拆分

**规划验收（本次完成到文档层）**：层级、范围、来源/置信度、写入同意、检索过滤、更新/删除、代理隔离及供应商披露已定义。

**实现验收（尚未开始）**：跨会话/项目/代理泄漏测试目标为0；记忆关闭后不得新增长期条目；删除后搜索/摘要/缓存不再召回；用户纠错覆盖旧记忆；无来源内容不被报为已记住；本地导出/删除和日志脱敏可测试。
