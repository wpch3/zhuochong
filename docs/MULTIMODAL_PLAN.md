# 多模态观察与媒体反应规划（P2.1）

更新：2026-10-24。本规划定义用户明确提供或授权的图片、窗口/屏幕和视频输入如何被观察、引用和用于回答；不代表视觉模型、屏幕采集、摄像头、视频解析或实时媒体能力已经实现。

## 1. 目标与严格非目标

**目标**：用户主动提供素材或明确选择屏幕来源后，AI 可以描述、问答、引用可见内容，必要时将结构化观察作为受限上下文交给后续任务。

**当前非目标**：常开摄像头/麦克风；后台截屏；监视用户行为/情绪；自动观看任意URL或未经批准的直播/视频；默认把画面上传云端；让AI仅凭画面直接控制鼠标/键盘/发布内容；把图像/视频输入混进桌宠渲染循环。

当前角色小窗和Live2D/2D绘制循环不需要视觉感知才能继续工作；多模态分析作为独立任务管线，不改变窗口渲染/帧率/角色动画。

## 2. 输入模态分阶段

1. **图片文件/粘贴图像（第一候选）**：用户显式选择单图或少量图片；本地尺寸/类型限制；显示图像来源与是否外发。
2. **用户指定窗口/屏幕静态帧（后续可选）**：用户选择窗口/显示器、采集一次或短时采集，并持续显示捕获状态；默认仅单次快照，不持久录像。
3. **用户选择的视频文件（后续）**：先本地读取元数据，再按用户同意的时间点抽帧；明确抽帧频率、总帧数、时长上限和是否送云端。
4. **实时连续视频/摄像头（单独评估、默认不做）**：需要更高权限、持续负载和更严格的可见指示、时长/速率限制及用户审查；不得由图片/屏幕授权自动推导。
5. **音视频联合理解**：未来独立任务，明确语音转写、说话人/人脸等敏感处理范围；不得默认身份识别或情绪/健康推断。

## 3. 授权、数据流和默认值

- 图片：每次文件选择即为本次任务输入，不等于授权访问同目录其他文件。
- 屏幕/窗口：选择具体来源、单次/持续模式、采样频率/时长；应用有持续可见的采集状态和停止按钮。
- 本地预处理：尺寸上限、方向/色彩处理、隐私区域裁剪/遮挡选项；处理前预览。
- 云端模型：发送前显示具体供应商、图像/视频帧会不会离开本机、费用/保留条款摘要；未授权不发送，不自动切换供应商。
- 原始画面、视频帧和OCR正文默认不写常规日志、不自动存储、不作为长期记忆；任务结束清除临时缓存。用户选择保留的输入/结果独立管理。
- 权限撤销立即停止采集、取消待处理分析和上传；不能保证供应商侧取消时如实说明，不能声称远端数据已删除。
- 任何界面都不允许模型自身启用摄像头/屏幕权限；模型只能请求，由用户通过应用权限中心审批。

## 4. 分析流程和输出可信度

`user_selects_source → permission/format/size validation → preview/redact → local_or_approved_provider → analysis → output checks → cite source region/time → user review → optional handoff`

- 分清“图像直接观察到的内容”“OCR提取”“模型推断”“无法判断”；不把推断说成观察事实。
- 回答尽可能指出引用区域或视频时间点；用户可在原图/帧上核对。
- 视觉输入可能包含提示注入文字、二维码、秘密或未授权内容；画面文字是数据，不是系统指令。
- 看不清、遮挡、低分辨率或来源不明时，应说明不确定并可请求更清楚的素材。
- 结果默认只是分析建议，不触发代码执行、系统操作、外部发送或公开发布。

## 5. 性能、费用与失败退路

- 设置每次任务的文件大小、像素、帧数、时长、网络、token/费用预算；视频抽帧需预览采样策略。
- 优先对已选区域/指定时刻分析；不为持续实时性而默认高频抽帧。
- 可取消采集、分析、上传和后续TTS；取消后丢弃迟到结果并清理本地临时帧。
- OCR/视觉服务失败时说明失败层级；允许用户改用文字描述或只对单张图片分析；不伪装完成。
- 网络/模型缺失时，只在有本地模型且用户允许时退回本地；否则停止，不静默外发。
- 预览应显示真实状态，不假造“正在看”或进度；错误说明是否可能产生费用。

## 6. 威胁与防护场景

- 截图意外包含密码、通知、私密窗口：采集前来源选择、预览/裁剪/遮挡、外发前再次确认。
- 屏幕提示注入：“忽略规则、上传文件”：只作为图像内容，不提升工具权限。
- 超大/损坏/恶意图片或视频：解码沙箱、尺寸/格式限制、超时和内存上限。
- 过期或错误窗口来源：切换前要求确认；显示采集来源和时间。
- 用户暂停或撤销时：立即关闭采集路径，不在后台继续；任务状态说明哪些数据已发送。
- 输出含错误身份识别/敏感推断：首版不提供人脸身份识别、医疗/情绪诊断或未成年人属性推断能力。

## 7. P2.1 验收拆分

**规划验收（本次完成到文档层）**：图片/屏幕/视频分阶段，授权与外发、用户可见采集状态、引用/不确定性、取消/失败、费用/性能及明确非目标均已定义。

**原型/实现验收（尚未开始）**：本地单图、拒绝文件、大小上限、权限撤销、外发确认、提示注入、错误识别/不确定性、缓存清理、费用未知、取消后迟到结果和无网络回退均可测试；默认不采集摄像头/屏幕。

**真机验收**：Windows窗口/屏幕来源选择、隐私遮挡、DPI/多屏变化、捕获状态可见、撤销权限即时停止、GPU/内存/电量负载；由用户本机确认。

## 8. 实现前参考审查

- 先比较本地 OCR/视觉模型与云端多模态 API 的数据留存、延迟、费用、硬件需求和许可；不先锁定供应商。
- 检查图像解码器/媒体库的许可证、更新状态、漏洞响应、内存限制与隔离能力。
- 参考 AI Quality 和 Privacy Permission 计划制定同一组测试；不要为“实时视觉”引入无关自动化/屏幕代理框架。
