# 参考模板流水线（Reference Sheet Pipeline）

> 立项于 2026-10-18 用户第十五问：
> 「要不这样，你先生成参考模板，像短发一样，你觉得呢？**没有目的的制作你做的太乱了**。」
> 「双马尾和马尾以及带兜帽都必须完整的生成参考模板图，**全身上下都必须和短发一致，除了发型**。」
> 「兜帽想要适配的四种发型，更必须生成参考图。」
>
> 用户是对的，而且这正是 Live2D 官方工序。本文把它定为此后所有造型件的**唯一入口**。

---

## 1. 为什么要有这一层

`docs/memory/POSTMORTEM_ART.md` 第一层已经写过根因，这里只重复结论：

| | 官方工序 | 本项目之前干的事 |
|---|---|---|
| 顺序 | **画师先画完整差分立绘 → 再拆图层** | 拿短发成品**挖开** → 贴 AI 单独生成的碎片 |
| 约束 | 整张图里所有部件共享同一套几何、透视、光照 | 碎片各画各的，**没有任何共同约束** |
| 结果 | 拆出来天然对得上 | 「一坨头发缠在一起」「兜帽和衣服合不上」 |

从第七问到第十四问，每一轮返修都在修同一类症状，因为**工序本身是反的**。
参考模板这一层就是把顺序掰回来：先有完整的差分立绘，再谈切件。

## 3. 生成规矩

1. **全部从同一张底图编辑出来，不互相串。** 串着改会累积漂移。
   唯一的例外是四张戴帽图：它们以「对应发型图 + 已定稿的 `sheet_short_hood.png`」
   两张一起当参考，这样兜帽样式能完全照抄，发型也不会走样。
2. **提示词里必须逐项点名"下面不变"**：同一张脸、同一件奶油色衬衫、
   同一件白+薄荷青连帽夹克、同一条藏青百褶裙、同一双条纹长袜、同一双球鞋、
   同一个站姿、同一个构图比例。光写"保持一致"不够。
3. **背景必须是纯洋红 #FF00FF 平涂**，抠像要用。
4. 兜帽的硬性特征（来自 `docs/REFERENCE_NOTES.md` 第四十七批）：
   米白光滑卫衣料外布、**薄荷青内衬**（必须和夹克领口那圈对上）、
   帽口厚折边（罗纹只在折边上，不要整顶针织，那是毛线帽）、
   白扁抽绳配银色金属头、**帽身与衣领肩线连续**并有聚拢的布料张力。
   禁止：披风、斗篷、蕾丝、扇贝边、荷叶边、帽子上的动物耳朵。
5. 发型的硬性特征：发型是**整套**——前髪 / 横髪 / 後ろ髪 一起变。
   扎起来的档位，**头顶必须跟着变**（看得见往扎点聚拢的走向），
   不能是"短发上挂一条尾巴"。

## 4. 套准（关键一步，不能省）

`tools/register_sheets.py`

就算提示词写得再死，AI 每张还是会带零点几个百分点的尺度/位移漂移。
实测首轮：三张链式生成的戴帽图**鞋底比底图低 5px、袜筒宽 3px**（约 0.4%）。
整图上完全看不出来，但参考模板的用途是**按同一套坐标切件**，
靠的是"同一个像素位置对应同一个身体部位"，漂了就全错位。

做法：解一个相似变换（等比缩放 + 平移），把每张图的**膝盖以下**
（y 1100~1520，裙摆之下只有腿、袜、鞋，任何发型和兜帽都不该动它）
对齐到底图，粗搜→细搜三轮，然后**只重采样一次**输出到 1024×1536。

```
ZC_PYTHON=/tmp/imgenv/bin/python python3 tools/register_sheets.py --character xiaoxun
```

套准后写 `sheets/manifest.json`，记下每张的变换参数、腿脚差异率、鞋底行号，
以及**图片内容的 sha16**。

实测结果（首轮）：

| 图 | 套准前腿脚差 | 套准后 | 鞋底 y |
|---|---|---|---|
| twin / pony / long | 0.98 / 0.97 / 1.72% | 1.55 / 1.54 / 1.95% | 1479 |
| short+hood | 1.35% | 1.98% | 1479 |
| twin+hood / pony+hood / long+hood | **4.14 / 3.78 / 3.95%** | **2.71 / 2.08 / 2.24%** | 1479 |

八张鞋底**全部落在 y=1479**。剩下的 1.5~2.7% 是线稿抗锯齿与重采样，不是结构错位
（看 `logs/asset_qa/reference_sheets_align.png`：红色只出现在长发垂下来的地方，腿脚带几乎没有红）。

## 5. 闸门

`tools/selfcheck_repo.py :: check_design_sheets` —— 静态检查，不依赖 PIL：

- 参考模板目录存在（不存在 = 还在用"挖成品贴碎片"的老工艺）
- 四种发型 × 兜帽收/戴 **铺满 7 张**
- **台账哈希与磁盘上的图一致** —— 换了图不重跑套准，这项立刻红，无法绕过
- 每张膝盖以下与底图差异 **≤ 3.0%**
- 每张鞋底落在**同一行**
- 画布统一

## 6. 下一步：从模板切件

模板到位之后，切件工具的输入就从"AI 单独生成的碎片"换成"同一套模板的差分"：

1. 对每一对（底图 ↔ 模板），算差分区域 = 这个档位真正改了什么。
2. 发型件从差分区域里取，**连同被它遮住的部分一起补画**（塗り足し，
   `docs/REFERENCE_NOTES.md` 第四十六批 A）。
3. 兜帽件从 `*_hood.png` 与对应发型图的差分里取，接在 `neck_back`（层 95，衣领裏）。
4. 因为所有模板共享同一套身体坐标，切出来的件**天生对得上**，
   不再需要逐件手调 `pos_rel` / `width_ratio`。

这一步做完，`attachments.json` 里那一堆手调的几何常数应该能大幅减少 —— 那些常数
本来就是在替"碎片之间没有共同约束"擦屁股。

## 判据的层级：颜色 → 区域 → **强差分**（2026-10-20 第二十五问）

切件判据踩过三代，后面的每一代都是前一代翻车逼出来的：

| 代 | 判据 | 为什么不行 |
|---|---|---|
| 一代 | `hair_like(颜色)` | 白夹克的近白描边、冷灰投影**在色相上就是发色**，怎么调阈值都分不开 |
| 二代 | `region`（diff>18 再 dilate 21） | 只能圈**范围**：它是松的，脸、衣服、线稿错位全在里面 |
| 三代 | **`newpaint`**（diff>42 ∪ 剪影外） | ✅ 现用 |

`newpaint` 之所以硬，是因为它问的问题不一样：不是「这像不像头发」，
而是「**画师在这一格新画了东西没有**」。七张模板共享同一套身体，
所以衣服、腿、袜子在任意两张之间差分天然为 0。

实测采样（`sheet_long` vs `design_sheet_short`，最大通道差）：

| 位置 | 差 | 判定 |
|---|---|---|
| 淡紫发压白夹克 | 34~49 | 头发 ✅ |
| 夹克冷灰投影 | 13 | 衣服 ❌ |
| 青袖 | 12 | 衣服 ❌ |
| 裙子 | 10 | 衣服 ❌ |
| 腿 | 9 | 身体 ❌ |

**三条使用纪律**（都是本轮用翻车换来的）：

1. **收尾必须是开运算**：`dilate(erode(despeckle(x,3,7),7),9)`。
   套准 1~2px 残差会沿高反差轮廓留细边，`despeckle` 滤不掉、`dilate` 一涨就是方块。
2. **不要拿 `dilate(base_op, N)` 去剪**：base_op 是**短发**底图的剪影，
   长发帘垂在身体外面，剪完只剩压在衣服上那一条（73596→37431）。
3. **件的下界放宽前先问「下面那一截是谁的地盘」**：
   crown 下界 chin+80→chin+160 原型很漂亮，实拍把整条衣领复制了一遍。

## 判据的第四代：**区域反选**（2026-10-20 第二十六问）

三代判据（颜色 → 区域 → 强差分）都是「正着问：这一格是不是头发」。
第二十六问发现第三代在**头部**这一段会翻车：

> 淡紫发 (216,216,232) 压在白夹克上，最大通道差只有 29；
> 实测模板上那一带 lavender 像素的 diff **中位数只有 11**，而 `newpaint` 的线是 42。
> ⇒ 「和短发底图长得一样的那部分头发」被整块剔掉，件变成一张破布。

| 代 | 判据 | 适用范围 |
|---|---|---|
| 三代 | `newpaint`（diff>42 ∪ 剪影外） | **身体那一段**：衣服在两张模板里完全一致，差分天然为 0，判得极准 |
| 四代 | **区域反选**：`geom & ~erode(face_t,5)` | **头部那一段**：这一带画面上只有脸/耳/颈/发四样，脸和耳和颈全在 `face_t` 里，**剩下的必然是头发** |

四代之所以成立，是因为它换了一个**封闭**的问题：
不问「这像不像头发」（开放、要靠阈值），而问「这属不属于那张脸」
（封闭、`face_t` 是正取肤色再 `fill_holes`，边界由线稿自己决定）。
这正是 ClipStudio 官方那句「**線画のやや外側を選択してくりぬく**」——
按轮廓切，不按颜色挑。

实现上**同一张 `face_t` 复用三处**，不再各写各的几何近似：

1. 头壳挖脸：`scalp_low = geom & ~face_cut`
2. 发帘躲脸：`side = side & ~face_cut`（原来是个矩形，正好把下颌两侧的发缕齐根切断）
3. 挡住塗り足し：`bleed = dilate(mk,9) & ~face_t`（头壳压在脸上面，往脸里补＝画脏）

> 腐蚀 2px（`erode(face_t,5)`）是关键：那 2px 是「发色×肤色」的抗锯齿混色，
> 整条削掉就是沿着每根发丝镶一串白麻点。

## 附：挂件姿态重铺（`tools/make_tail_poses.py`，**手动步，不在 rebuild 链里**）

猫尾四档不是四张画，是**一条原画 + 三次几何重铺**（依据见 REFERENCE_NOTES 第五十一批：
「揺らす前提ならば、尻尾はまっすぐ描いておく」）。这一步**不在** `rebuild_parts.sh` 里，
因为它要写 `design/redraw/*.png` 和 `design/attachments.json` 这两份**入库源文件**。

跑的顺序（它读写 `attachments.json`，必须排在两个 wire 之后、`make_attach_parts` 之前）：

```
python tools/wire_sheetcuts.py          # 先，会重写 hair_* 的 recolor_match
python tools/wire_hoodcuts.py           # 次
python tools/make_tail_poses.py         # 再，重铺三档 + 反解 pos_rel/sprite_h_rel（≈17s）
python tools/make_attach_parts.py --character xiaoxun --form teen
python tools/make_rig.py --character xiaoxun --form teen
```

改了姿态曲线（`th_up` / `th_puff` / `th_tuck` / `puff_scale`）之后**必须实拍四档对照**，
别只看闸门：根部坐标全对、画面上照样可能整条藏在躯干后面（层 `hip_back`=30 在身体之后）。

## 4. 髮だけ差分：给後ろ髪一个自己的源头（T67.7，2026-10-26）

### 4.1 为什么前面三层的工序还是不够

前三层（完整立绘 → 套准 → 切件）解决的是"同一张图上切下来的件天然对得上"。
但它有一个前提没说出来：**切下来的件，里面的像素必须都是这只件自己的**。
後ろ髪违反了这个前提 —— 它被身体挡着，而掩膜是按"头发的轮廓"画的，
轮廓里面明明是**衣服、手、裙子**。

于是 `hair_long_back@2x.png` 里烤着：
两只戴袖口的手、白衬衫的衣扣、裙子、鞋（`logs/asset_qa/t67_7_hair_only_candidate.png` 左图）。
它在层 58（最底），静止时被身体盖住看不出来；一旦 `ParamHairSway` 让头发形变，
那些被盖住的副本就会从身体轮廓边缘**漏出来 2~3px** ——
就是用户截图里那条"灰紫色腕带"和那些粉色指尖。

三条抢救路线都失败了（G66.24）：按颜色洗洗不掉（幽灵被洗淡，与发丝高光同色域）、
按身体掩膜擦不到（可见幽灵在轮廓外一点点）、按连通块删不干净。
**根因不在清洗算法，在源头**：这张图本来就不该这么做。

### 4.2 新的一层：只画头发的图

Live2D 工序里这叫「髪だけ差分」——发型件单独出一张，**不含身体**。
我们照这个做：

1. **出图**：以 `sheets/sheet_long.png` 为参考，生成"只有长发、洋红底、无身体无衣服"的一张。
   提示词必须点明：只要頭髮、纯洋红 #FF00FF 底、发尾是**长短不一的尖**（不许平切）、
   内缘是**有机曲线**（不许直边、不许台阶）、发色与参考一致。
2. **抠像**：`tools/key_hair_only.py`。三件事：
   - **反预乘**（`C=(观测色-(1-a)·键底)/a`）+ **去溢色**（把偏洋红的像素的 G 抬回去）
     —— 二值化会在轮廓上留一圈粉边，用户明令禁止彩边；
   - **判据只看 `min(R,B)-G`**：洋红是 R、B 高 G 低，本角色头发是冷紫（B 略高于 R≈G），
     用这条判别不会误伤头发自身的紫；
   - **补孤点**：深紫阴影会被当成洋红抠出小洞，只补"全透明但被 ≥200 不透明包住"的点。
3. **配色对齐**：`--match-palette` 拿参考立绘的发色均值做逐通道增益。
   v1 实测 (179,175,204) → (191,189,216)，残差 **2.6/255**（门槛 ΔE<3）。

产物：`design/redraw/hair_only/hair_long_backonly_v1.png`（`_raw` 是未抠像的原始输出，留着备查）。
体检：不透明 451,818px、**洋红彩边 0.00%**、直边 28px、近白 2.8%（旧件 26.2%）、
空洞 1.62%（发绺之间 8~10px 的缝，目视核过 `logs/asset_qa/t67_7_haironly_holes.png`，不是缺块）。

### 4.3 还差什么（T67.25）

- **去呆毛**：v1 顶上带一根，而呆毛是独立件 `hair_ahoge`，会撞；
- **顶部塗り足し**：现在头顶是平切的，要往上补一段，好塞进头后面；
- **注册**：按 `body_full` 像素系套准（和 `cut_from_sheets.py` 同一条仿射），
  量 `pos_rel / sprite_h_rel`，不手调；
- **切五组**：后发 / 侧发×2 / 胸前发×2，各自一张完整图 + 逐束网格（方案 A）；
- **接物理链**：`hair_long` 的摆链输入要重新标定。

这五步做完之前，**旧件不许删**，新旧并存着比。
