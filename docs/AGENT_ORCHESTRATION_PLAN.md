# 代理区编排与监督规划（P1.4）

更新：2026-10-24。本文件定义代理运行模型与人类监督，不代表多代理后端、独立代理进程或自动化工具已经实现。代理不得超出权限中心、代码区与生成区已授予的能力。

## 1. 产品概念与边界

- **Agent profile**：角色说明、模型/供应商策略、允许工具/Skills、数据范围、最大并发/步骤/成本、禁止事项。
- **Agent run**：为一个用户目标创建的一次执行实例，具备 run_id、任务 ID、计划版本、上下文引用、预算、状态和最终报告。
- **Step**：有明确输入、依赖、负责 agent/工具、权限、预期输出、超时和验收的原子步骤。
- **交接**：代理之间传结构化结果/引用/差异/未解决问题，不默认分享完整聊天记录或全部记忆。
- **人类审批**：权限扩大、高影响操作、外发、写文件、执行命令和无法逆转操作必须在执行端门控；模型声明“用户同意”不算授权。
- **Agent 不是系统管理员**：不能自授权限、修改安全策略、创建隐藏代理、卸载监控、读取未授权工作区或绕过额度。

## 2. 代理配置

每个 profile 至少声明：
- 身份/用途/任务类型和不适用场景；
- 使用的模型/供应商及是否允许云端处理；
- 可用工具与 Skills 的 allowlist；
- 允许读取/写入的目录、会话与记忆命名空间；
- 网络目标/动作能力；
- 每任务 token/费用/时间/步骤上限和并发限制；
- 哪些动作自动批准、哪些必须逐次确认（高影响动作不得设为静默自动）；
- 输出格式、验证器和失败退回策略；
- profile 版本与用户编辑记录。

未经用户选择的 agent 不应在后台自行启动；提供只读/规划模式，首次执行写操作时先逐项审批。

## 3. 任务拆解与计划确认

1. 接收用户目标，识别输入文件、输出目标、期限、预算、敏感度与可能副作用。
2. 若目标不清或涉及不可逆动作，先问澄清/确认；禁止假设默许。
3. 生成可编辑计划：步骤、依赖、执行者、工具、所需权限、预期产物、风险与成本估算。
4. 验证计划无循环依赖、互斥写操作、超预算、越权数据流；缺权限时标记“等待授权”，不可先跑后问。
5. 用户批准具体计划版本；任何实质范围/权限/预算变化均需重新确认。
6. 执行时更新任务状态和实际证据；完成后按原验收条件核对，不以代理自评代替测试。

## 4. 调度、并发与共享

- 有依赖的步骤按拓扑次序执行；可并行步骤须无共享写目标冲突、无重复收费风险。
- 代理和 Skill 每次工具调用都由统一权限检查，不因处于同一 run 自动继承所有权限。
- 多 agent 默认隔离会话和记忆；只通过用户批准的结构化交接共享最少必要信息。
- 避免代理互相递归委派；每个 run 有最大代理层级、总步骤、总成本、墙钟时间和重试上限。
- 独占资源（文件、麦克风、GPU、某供应商并发）需锁定或调度；锁超时会释放并回报。
- 代理输出必须标注它是建议、工具结果、模型推断还是用户确认事实。

## 5. 用户可见监督

Run 概览展示：目标摘要、当前计划、已完成/进行中/待审批/失败步骤、累计预算/费用、等待原因、最后更新时间和产物。

用户可：
- 查看计划与每步证据/输出；批准、拒绝、修改计划或缩减权限；
- 暂停、取消、重试单步或整次 run；停止应向下传递到子代理、进程、队列、TTS 和网络调用；
- 查看 diff/产物并选择保留或回滚；
- 查看模型/Skills/供应商版本与本次数据流。

等待审批时不能自动超时批准。长时间无响应可暂停整个依赖链并释放资源；恢复前重新检查权限和输入是否仍有效。

## 6. 记忆与状态恢复

- Run 需要区分临时计划状态、工具结果、用户批准决策和可复用项目记忆。
- 执行状态保存最少必要的 checkpoint；恢复后提示哪些步骤已完成、哪些可能重复计费/有副作用。
- 不在进程崩溃后自动重播外发、付费、写文件或不可逆工具动作；必须先查询幂等/执行结果或请求用户确认。
- Agent memory 按 profile/项目/用户授权隔离，可检查、纠正、删除；不能让一个 agent 默认看到其他代理历史或所有工作区。
- Prompt injection/网页或代码中的指令仅作为不可信输入，不得修改 profile、权限或计划批准状态。

## 7. 失败、取消和安全

- 错误类别：输入不充分、权限拒绝、工具失败、供应商/网络错误、预算/时间上限、校验失败、冲突、未知。
- 失败后代理可建议替代计划，但不能自动扩大权限、切换到更高成本供应商或改走未授权网络路径。
- 可重试步骤必须判断幂等与费用；非幂等动作重试前读取执行结果或要求确认。
- run 取消应幂等、传递到所有子步骤、终止本地子进程、阻止迟到响应覆盖任务状态，并报告可能无法远端停止的调用。
- 工具结果校验失败时停止依赖步骤；未验证结果不得作为后续步骤的事实输入。
- 安全审计记录 run/step/profile/tool/permission grant ID/结果类别，不写秘密和完整敏感内容。

## 8. P1.4 验收拆分

**规划验收（本次完成到文档层）**：profile、计划审批、依赖调度、并发冲突、结构化交接、预算、可见监督、取消传播、checkpoint/恢复与失败规则已定义。

**实现验收（尚未开始）**：模拟 agent DAG 覆盖计划变更审批、权限拒绝、冲突写入、递归委派阻断、并发限额、成本/步骤上限、取消传播、崩溃恢复不重放副作用、错误证据核对、隔离记忆及审计脱敏。

**交付验收**：成功报告含计划版本、实际变更/产物、逐项验收证据、未完成项、精确测试结果、成本、风险和回滚路径；不将虚构执行/测试状态标为已完成。
