# T2.1.1 表情候选 A：素材、运行时接入与交互验收

日期：2026-10-24

## 结论与状态区分

- **素材通过：** 9 套眼件候选的左右贴图均通过透明边缘、尺寸、对齐和 `@2x` 检查。
- **引擎能力实现：** rig 表情支持 `part_overrides` 的显式 opacity 目标和 `dx/dy`，跟随表情淡入淡出；部件引用在加载时校验，且与动作覆盖叠加。
- **正式 rig 接入：** teen 正式 rig 已接入 calm、smile、happy、shy、angry、sad、surprise、thinking、sleepy 九套候选眼件；非活动候选默认透明，不改变原始待机画面。共 18 个眼部候选部件，`@2x` 图按原尺寸两倍缩放。
- **动态交互验收：** 逐一运行九种表情并核对预览帧；另用运行时冒烟测试确认活动候选眼件仍响应左右 gaze、手动 blink；现有 smile 表情与 U viseme 组合测试确认口型不会被候选眼件改写或遮住。
- **嘴部候选：** 源包中的 9 个嘴部贴片仍只作为候选资产，没有加入 rig；T2.1.1 是眼件任务，运行时嘴型继续由既有参数/viseme 系统控制，避免静态嘴图冻结 lipsync。

## 素材验收

- 来源：`characters/xiaoxun/parts_src/expressions_a/`（8 张）与既有微笑图；平静态取当前 teen `body_full.png`。
- 9 个情绪候选：`calm / smile / happy / shy / angry / sad / surprised / thinking / sleepy`；另有 `closed` 眨眼候选，不计作第十种情绪。
- 候选包：30 张 RGBA 原尺寸贴片（每情绪左右眼各一 + 嘴一）；眼件 75×52、嘴件 44×28；所有 30 张均有对应 `@2x` PNG，分别为 150×104 与 88×56。
- 当前报告内洋红残留均低于 200；拆件与 rig 锚点 QA 为 6/6 通过，包含 1×/2× 配对尺寸、RGBA/透明通道及候选位置回投原模型眼锚点检查。
- `calm` 的三个原尺寸 PNG 已基于当前 teen `body_full.png` 更新；其余候选原件未被批量覆盖。一次环境重跑有 27/30 个输出与已有素材不逐字节相同，差异原因尚未隔离；因此保留既有候选。后续如需可复现重建，应锁定图像工具版本并核对源图哈希。

## Rig 接入细节

- 文件：`characters/xiaoxun/forms/teen/rig.json`。
- 表情级部件覆盖是显式 opacity 目标；因此基准 opacity 为 0 的候选部件可淡入，退出表情时回到基准状态。当前九个情绪各自隐藏常态眼件及其他候选件，只显示对应左右眼件。
- 候选开眼件带 `gaze` 与 `eye_open` 标签；闭合笑眼候选（happy）不带虹膜视线标签，避免把闭眼形状横向挪动。睫毛/闭眼件以及原始 blink 参数通路保留。
- 18 个互斥候选件获得唯一 layer 238–255；原来 240 及以上的层整体后移 16，保持刘海、眉毛、侧发的既有前后关系并通过唯一层号检查。
- 一致性复核发现初版手工位置确有偏移，已用原 rig 睁眼虹膜/笑眼锚点重新标定：calm 直接按当前 `body_full.png` 在 teen 画布中的位置投影；其余标准化候选的 canonical 86 px 眼距映射到原 rig 的 74.39 px，单倍图 scale 为 0.865（`@2x` 为 0.4325），按裁切原点计算 `pos`。新增回归测试锁住 `pos / anchor / scale`，避免缩略图观感掩盖锚点漂移。
- 冻结时钟下将 calm 候选与未覆盖的原 rig 对照，眼睛区域保持一致；蓝色虹膜质心偏差约 0.7–1.5 个预览像素（脚本对 calm 的原 rig 锚点容差为 2.5 个 rig 像素）。
- 当前只接入 teen rig；其他形态未改。
