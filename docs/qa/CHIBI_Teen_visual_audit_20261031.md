## Teen 目视审查

使用同一真实 C 引擎检查 Teen 默认服装、`cocoa` / `midnight` 换装、`long` / `twin` / `pony` 发型、兜帽与尾巴姿态，以及 `wave` / `tiptoe` / `curious_tilt` 动作。

- **服装**：默认、可可针织、夜航三套在静帧中整体配色和衣身覆盖基本一致，未看到明显服装错位；仍需在动作中复查袖口、腰线和裙摆。
- **发型**：`long` 在头部眼线高度出现横向断口，长发两侧有明显碎裂/透明边；`twin` 双马尾根部和鬓侧有断缝、碎片；`pony` 马尾根部与冠部也有可见接缝。三种发型均未通过目视验收。
- **兜帽/尾巴**：兜帽上档静帧可见；马尾与兜帽/肩部区域有遮挡关系需再验。尾巴 `puff` 姿态能显示，但需随动作复核摆链和身体遮挡。
- **动作/骨骼**：`wave` 右臂姿势可见，但左臂骨链仍被判为近直线（夹角 175.74°，`straight_fault=true`）。`tiptoe` 两臂为 175.74° / 177.91°，采样帧也未能清楚确认脚跟抬升；`curious_tilt` 两臂同样近直线。需按动作全时间线检查动作曲线、肘/腕枢轴、踮脚高度与骨链，不以单帧截图作通过结论。
