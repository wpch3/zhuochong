## 铁律：桌宠 Q 版 ≠ Live2D Chibi

桌宠 Q 版与 Live2D 骨骼立绘是不同视觉产品，分开命名、分开归档、分开验收；不能因为都叫 Chibi 就混用比例或画风。Live2D 新参考以用户 image-24 为比例/风格锚点，并按项目设定稿保持人物一致。逐图目视头身、发束数量/发根、帽兜关系、服装和整体风格，记录优缺点。概念参考不是可直接切入产品的贴图。

## 手型补充：小巧手 + 手套感 / 连袖感手型（2026-11-01）

用户明确要求两种都保留，不可互相覆盖：

- **小巧手**：保留此前选定的纤细小手。Chibi 原设定 `characters/xiaoxun/design/design_sheet_chibi.png` 是腕口/袖口与手掌结构的首要真值；放大存档 `chibi_design_cuffs_hands_zoom.png` 可见手掌短小、略尖并有简化分叉，腕根接在青绿袖口下。袖口有青绿与白色横条，必须保持连续。用户 image-24 与已选短发图只作比例/笔触参照。
- **手套感 / 连袖感手型**：`chibi_hand_mitten_user_marked_2026-11-01.jpg` 是用户红圈标出的正向造型参考。目视特征是袖口下接更短、更圆钝、手指分隔更弱的简化手型，整体有手套/连袖的观感；它是风格参考，不是可直接抠成贴图的源文件。
- **实现决策**：两种作为独立左右手件并通过 `hand_style` 切换；默认保留此前的小巧手，另一档是 mitten。手型选择须与手腕运动、动作手势正交，切换时不得丢失任一套素材。袖口条纹、腕根遮挡和插入深度以 Chibi 设定稿为准，不拿 Teen 手件补齐。
- **当前结构事实**：现有 Chibi `rig.json` 只有 `seg_arm_l/r`，没有独立 `hand_*` rig 部件；因此“已具备两个 Chibi 手型”不成立。双手型实现契约与验收表见上级目录 `hand_style_variants_2026-11-01.json`。该契约是隔离计划，不是生产资产或引擎验收证据。
