- `[沙箱实测]` `check_assets.py --character xiaoxun --form teen`：**1792 项，8 项不通过**（JSON 见 `check_assets_teen.json`）：

## 三、本人目视（铁律 1/2：亲眼看放大图）

### 3.1 少女 teen

- **短发静止全身**（`teen_idle_short.png`）：全身比例、配色、猫耳尾巴基本成立，脸部干净。**这是 teen 唯一可看的状态**，但仍有发丝边缘轻微粉边、手部手指偏细。不能代表全形态通过。

- **双马尾**（`teen_twin.png`）：全身可看，但与 §2 的 twin 侧发漏底 7–18% 对应——静止看似无洞，摆动/转头时会露透明。需动作极值复验，本轮未过。
