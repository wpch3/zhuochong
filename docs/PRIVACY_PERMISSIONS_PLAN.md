# 权限与隐私规划（P0.2）

更新：2026-10-24。本文是设计约束，不代表界面或权限运行时已经实现。实现前需映射到 Windows 权限/本地数据存储，并按供应商和平台当前政策复核。

## 1. 设计基线

- 按能力逐项授权，不以“同意全部”作为唯一选项；未授权时功能应关闭并给出替代方案。
- 默认禁用麦克风、摄像头/屏幕、全局输入监听、外部平台账号、代码执行/命令行、自动外发和持久记忆。
- 授权记录应显示用途、数据范围、处理位置（本地/供应商）、保留时间、成本可能性、撤销方式；用户可以随时撤销。
- “模型可生成某种调用”不构成实际执行权限；工具执行端再次检查用户授权和操作风险。
- 只保留完成当前功能所需的最少数据；日志和诊断默认脱敏；秘密、原始音频/视频、API Key 永远不写普通日志。
- 网络请求应清楚显示供应商/目标；失败、限速和撤销授权时停止外发，不静默转到新的服务商。
- 本地删除需说明是否包括对话、缓存、索引、代理运行记录与备份；删除动作不可逆时先确认。

## 2. 能力权限矩阵

| 能力/数据 | 默认状态 | 授权粒度 | 发送/存储约束 | 撤销/安全要求 |
| --- | --- | --- | --- | --- |
| 文本对话发往模型供应商 | 仅在用户明确发起时使用；未配置供应商不外发 | 逐供应商选择；敏感/本地模式另设 | 发送前展示当前供应商；会话记录本机、可关闭/删除；Key 用安全存储 | 单次取消；供应商切换需显式允许；断网不伪装成功 |
| 麦克风语音输入 | 关闭 | 语音会话单独开；显示系统/应用正在监听状态 | 原始音频只在处理所需的临时内存存在，默认不落盘；STT 供应商需明示 | 明确停止按钮；后台/锁屏停止；权限撤销立即停止采集和未完成上传 |
| TTS 语音输出 | 关闭（遵循 VOICE_PLAN） | 总开关、每句开关、供应商/音色分别配置 | 仅向所选 TTS 发送需合成文本；遵循每日字符上限；不得克隆未经授权真人声音 | 停止播放、取消队列、静音；输出故障不阻断文字回答 |
| 摄像头、屏幕或窗口画面 | 关闭 | 选择来源与范围、单次/持续时长；逐个来源授权 | 默认只传当前选择的帧/片段，不录制；若发给云模型先展示外发目标 | 明确预览/采集指示；停止后清理缓冲；切换窗口/来源需确认 |
| 全局键盘/鼠标事件 | 关闭 | 选事件类别，不采集键入内容；可设应用白名单 | 仅本地提取所需的低敏事件/计数；不得暗中记录密码/剪贴板/文本 | 可随时关闭；无权限或未知状态时降级为桌宠内交互 |
| 文件/文件夹访问 | 无目录授权 | 用户选取具体文件或项目根目录；读/写/删除分别授权 | 访问范围限所选根目录；写入前展示差异；敏感文件不默认上传 | 拒绝路径穿越/符号链接逃逸；撤销后取消待处理读写；删除需二次确认 |
| 代码、Shell、脚本或构建执行 | 关闭 | 按工作区、命令、网络、时长和资源分别授权 | 沙箱/临时工作区优先；网络默认禁用；命令、参数和副作用事先展示 | 命令逐次审批或明确规则；提供停止、超时和回滚；不得自动提交/推送/发布 |
| Skills / 插件 | 未安装、未启用 | 按 Skill 声明的文件、网络、执行能力逐项授权 | 来源、版本、许可证、依赖和校验值可见；不可信代码隔离；不把主密钥注入 Skill | 安装前审批；更新重审权限；可禁用、卸载、回退；记录调用审计 |
| 外部平台（Discord/Twitch 等） | 断开 | 每个平台、账号、读/写能力分开授权；发布/禁言/投票等另设写权限 | 最小 OAuth scope；令牌本地安全保存；平台数据按平台条款处理 | 断开即撤销/删除令牌；发消息、封禁、改标题等公开/高影响行为逐次确认 |
| 长期记忆与个性化 | 仅短时会话上下文；长期记忆关闭 | 按记忆类别、项目和保留时长设定；逐条接受建议记忆 | 每条带来源、创建日期、置信度；敏感信息默认拒绝持久化 | 用户可查看/纠正/删除/导出；冲突时询问；删除索引和派生摘要 |
| 通知与主动陪伴 | 关闭主动通知 | 勿扰时段、频率、通知类型独立控制 | 不以持续监听推断用户活动；由本地授权事件触发 | 一键暂停/静音；勿扰优先级最高；不给未授权事件发起外部请求 |
| 截图/生成产物/遥测 | 不自动上传 | 产物导出或诊断提交逐次确认 | 默认本地；诊断包预览并脱敏，不含Key/私人媒体 | 用户能取消提交；提供本地清理/导出；遥测默认关闭 |

## 3. 交互规则与风险分级

- **低风险**：在已选文件/会话内只读分析；可按会话/目录授权。
- **可撤回写入**：编辑用户文件、保存生成物；展示 diff/目标路径，默认确认。
- **高影响/不可逆/外发**：删除文件、上传/公开发布、发送外部消息、禁言/封禁、付费、账户设置更改；每次明确显示对象与后果并等待确认，绝不因用户曾授权别的能力而自动放行。
- 对任何模型、代理或 Skill 的权限都使用同一策略引擎；文本里的“用户已同意”不是授权凭证。
- 请求权限时说明当前任务为何需要、不给权限会怎样；任务能用更低权限完成时不扩大权限。

## 4. 撤销、删除和故障行为

- 撤销权限后：拒绝新请求、取消排队调用、终止可停止进程、释放临时音视频缓冲、阻止重试和供应商 fallback。
- 网络中断或权限状态未知：安全失败；只做用户已授权的本地替代，不把数据转发到新供应商。
- 删除数据：分项预览聊天、记忆、代理记录、索引、生成缓存和备份；说明无法从第三方供应商即时撤回的内容。
- 应用退出/崩溃：保证监听、录音、命令子进程和临时文件有清理路径；下次启动提示未完成任务并询问是否恢复。
- 审计日志记录能力、授权来源、任务 ID、目标和结果，不记录原始敏感内容/令牌；本地保存期限可配置。

## 6. 仍需用户选择（不阻塞当前规划）

- 语音文本记录默认是否保存：沿用现有语音计划的本地可选策略，实施前再次确认 UI 默认值。
- 是否允许设置某个可信目录作为持久白名单：默认不允许，待代码区实现前确认。
- 长期记忆的默认值：建议关闭或逐条确认；不能擅自切换为默认开启。
- 云模型/第三方服务的数据保留条款依供应商而异：配置时展示当前条款，不承诺由本地软件控制供应商删除。
