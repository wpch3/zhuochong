# 小寻 2D 角色与自研 rig 完整度规划（P1.10）

更新：2026-10-24。本文件把现有“小寻拆件、表情、动作、服装配饰”计划整理为可执行的原画与引擎验收顺序。当前引擎是项目自研 C 数据驱动分层 rig；本规划借鉴 Live2D 表现目标，**不代表已经使用 Cubism 模型/运行时**。本任务只处理 2D 角色，不包含 3D/VRChat。

## 1. 固定边界与素材原则

- 四形态轴保持封板：少女、萝莉、青年女性、Q版；不得借素材补缺扩展年龄/形态轴。
- 原画/服装/配件按用户参考图 REF-FIRST；用户提供/批准参考后再做设计稿或素材，不以程序化绘图取代角色原画。
- 先完成一个形态的一套完整可验收基准，再考虑把规范复用到另外形态；不把“机制能换装”说成“素材已齐”。
- 新配饰候选包括用户提到的腕带、耳环；其他配件只有通过小尺寸可读性、锚点、物种特征与遮挡审查才做。不是必须凑满清单。
- 任何服装/饰品造型和资源量均由用户审阅；规划完成不等于批准具体美术方案。
- 角色默认外观和现有桌宠行为不得被未验收素材覆盖；保留可回退的素材版本。

## 3. 素材制作次序（REF-FIRST）

1. **基准参考板**：按现有参考图确认当前形态/常服/尺寸/配色/配件空缺；标出素材已有、机制已有、素材未有三类。
2. **面部先验收**：固定眼位、眉位、嘴部暗线边界；对表情集做同画布对齐和拼合对照图；不合格的素材不进入角色目录。
3. **补遮挡与拆件**：头发、脖肩、关节和衣物交叠区域先补全被遮挡像素；检查全身静止重组。
4. **关键表现件**：眼/眉/口和头发的最小完整集，驱动眨眼、目光、情绪、句级/音素口型（依音频能力）。
5. **身体与动作依赖件**：肩臂手、裙摆、腿袜鞋等；先支持用户最常见的互动与待机动作。
6. **轴7日常配饰与衣装层次**：默认桌宠尺寸盘点 → REF-FIRST 参考板 → 少量候选 → 试做/质检一套衣装厚度 → 组合/遮挡/开关回归。腕带和耳环仍是待用户审阅的候选，不提前画具体造型。
7. **通过单形态验收后再复用规范**：检查资产命名、锚点、色彩和 rig 数据；其余形态重新按各自参考审核，不直接缩放复制所有部件。

## 4. Rig 参数与动作模型

- 建立稳定的 group/part/anchor/parameter 命名表，记录父子层级、绘制顺序、局部原点、缩放范围、可见条件和服装插槽。
- 通道覆盖位移/旋转/缩放/透明度/变形（如实现）；支持动作曲线、缓入缓出、优先级、可打断、循环/一次性、回待机、多个通道混合。
- 面部参数由情绪、眼动、眨眼、说话分别控制；冲突有确定的合成顺序，提供手动覆盖与重置。
- gaze 目标支持鼠标/对话方向/回正，限制在眼眶遮罩；失去目标平滑回中。
- 物理参数可按质量档/暂停状态调整；暂停后是否快照或停止以视觉一致性测试确定；避免物理改变角色可点击区域。
- 换装/发型/配饰通过槽位、挂点和 layer 管理；切换失败回到已知有效外观，不留半套组合。
- 若网格形变可能改善转头/脸颊表现，先做小范围性能/质量比较；不把 mesh warp 预设成必须，也不混淆它与 Cubism SDK。

## 5. 表情、口型与情绪联动

- 情绪状态、脸部素材、动作和台词分层；情绪衰减与次要情绪叠加由规则控制，不因长期状态锁死某张脸。
- 表情最小集优先覆盖中性、开心/微笑、害羞、生气、难过、惊讶、思考、困倦；每项有参考图和人工验收。
- 眨眼和情绪眼型协调：闭眼素材不丢睫毛/眼线，睡眠与普通眨眼区分。
- 口型路线：先闭口/开合视觉可用，再实现 AEIOU/供应商音素时间戳或音频包络；无驱动时只称为占位动画，不称同步口型。
- 字幕/气泡与面部表情保持可读；不为显示字幕扩大默认角色窗口或挡脸。

## 6. 自动化与目视回归

- 素材机器检查：分辨率/画布一致、透明通道、键色/白边残留、轮廓裁切、色卡偏差、文件体积和元数据。
- 合成检查：静态拼回参考，差异图定位错位；单件/组合预览；裁切/锚点/前后层可视化。
- rig 测试：所有动作端点/中断/回归，所有表情组合，眼/口/发/衣/配饰开关，随机场景切换。
- 视觉测试矩阵：默认桌宠尺寸、较小/较大缩放、高 DPI截图、透明背景/深浅背景、不同发型/服装/配饰组合。
- 目视验收由用户或明确可用的图像审阅流程完成；静态断言、HTTP 200 和资产文件存在不等于素材好看或穿帮检查通过。
- 真机项单列：Windows透明窗/穿透、帧率、缩放、多显示器、连续运行、暂停/唤醒和动画观感。

## 7. P1.10 验收拆分

**规划验收（本次完成到文档层）**：素材矩阵、REF-FIRST次序、rig/动作/物理参数、口型真实性、配饰轴7、自动化与目视/真机验收已整理。

**素材/实现验收（尚未开始或按TASKS现状执行）**：现有 `T2.1` 具体素材和实现状态逐项为准；每个素材项必须过机器检查+拼合对照，服装/配件经用户审阅，不因为P1.10规划完成而标作素材完成。

**非目标**：不新增形态；不在本任务引入Cubism Core；不做3D/VRChat；不改变现有角色视觉定稿和当前Live2D/2D桌宠交付。
