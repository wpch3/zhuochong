### DC07 ✅ 交叉淡化曲线照抄官方 `CubismPose::DoFade`，不自己发明（2026-10-14）

- 前提：桌宠窗口是透明的，交叠期"没盖住"的部分漏的是桌面（不是黑底）。
- 证据：官方常量 Phi=0.5 / BackOpacityThreshold=0.15
  （<https://docs.live2d.com/en/cubism-sdk-manual/pose/>）；
  `tests/test_core.c::test_xfade` 真渲染一帧，中点合成不透明度 **0.85**。
- 负控：✅ 把 `zrig_xfade_hidden` 改成线性 `1−w`，三条断言同时红（中点量到 0.753）。
- 复查触发：上了部件离屏合成（G96）之后，这条可以升级到总覆盖 1.00。

### DC08 ✅ 姿势类动作用 `pulse`，不用 `bounce`（2026-10-14）

- 前提：`bounce = amp·sin(π·ease(t/dur))` 的峰值只是一个瞬间，不是一段保持。
- 证据：把 `eval_channel_wave` + `ZEASE_OUT_BACK` 在 Python 里逐行复刻，
  按 60fps 解析算出 **v>0.95 只持续 48ms**；改 pulse 后引擎实测抬起 ≥14px 持续 **693ms**。
- 负控：✅ 两种波形在同一条测量管线下对比（同一脚本、同一采样率）。
- 复查触发：引擎的波形或缓动公式改了，复刻脚本要同步改（否则算的是旧引擎）。

### DC09 ✅ 腿件不但要擦像素，还要**裁画布**（2026-10-14）

- 前提：引擎 bend 曲线的 `t` 是**贴图画布**的 0..1，不是解剖位置（读源码确认）。
- 证据：不裁时脚踝 t=0.774 → tip 0.59（摆腿 20px 只剩 11.6px）、sine 0.65
  （屈膝抬脚 2.9px）；裁完实测摆腿恢复满额 40px 行程（`/api/param?id=ParamLegL` 抓帧量）。
- 负控：✅ `check_assets` 新闸「腿件画布裁到切线」，把画布改回去立刻红。
- 复查触发：任何改贴图内容边界的工具都要问一遍"画布还代表原来那段解剖吗"。

### DC10 ✅ 共用参数的补偿要加在**动作**那一层，不加在参数上（2026-10-14）

- 前提：`ParamBaseY` 被 6 个动作共用，而 happy 是**跳跃**（脚本来就该离地）。
- 证据：给 BaseY 加脚补偿会把 happy 的跳跃抵消掉；改为在 tiptoe 删掉这条通道，
  实测动作期间最底行从 747→744 恢复为恒 747。
- 负控：✅ `check_feet_on_ground` 把 happy 的 amp 调大 → 立刻红（声明 34px vs 实算 48px）。
- 复查触发：新增会动 `root.dy` 的参数时，这条闸会要求动作显式声明 `airborne`。

### DC11 ✅ 交叉淡化窗口取 `[0.40,0.60]`，到此为止不再加消重影机械（2026-10-14）

- 前提：官方对"交叠期双轮廓"只给了"尽量减少"（重叠区小 + 轮廓羽化 + 加变形），
  **没有彻底消除的办法**（<https://docs.live2d.com/zh-CHS/cubism-editor-manual/change-pose/>）。
- 证据：解析复算窗宽对照表 —— [0.25,0.75]=6 帧/100ms，**[0.40,0.60]=3 帧/50ms**，
  [0.45,0.55]=1 帧/17ms；重叠带 38px 且被鞋完全盖住（逐像素量到外露 **0**）。
- 负控：✅ `check_foot_switch` 把窗口放宽到 [0.1,0.9] 立刻红。
- 复查触发：窗口再收窄会牺牲过渡平滑度；真要消干净得上离屏合成（G96）。

  在这个前提下"绕趾尖转 φ" ≡ "以地面线为原点纵向拉伸 k=sin(θ+φ)/sinθ"，横向不变。
- 证据：`characters/xiaoxun/forms/teen/sprites/foot_parts.json`（lift=30 / ks=0.65 /
  ku=1.2967，两张姿态图鞋底同在 y=1291）；引擎内实测 ParamTiptoe 0→1 时
  画面最底行**恒为 747**、人物顶行 37→20；`logs/asset_qa/tiptoe_final.png`。
- 负控：✅ 8 个数据负控（去 `bend_follow` / 放宽淡化窗 / 层序对调 / 拆平台 /

- 复查触发：换角色/换画风（俯角不同）时 θ 要重新量；鞋型改动要重跑 `--qa`。
