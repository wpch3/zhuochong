## T51 全平台聊天互联兼容（国内外）

- **目标**：小寻在桌宠内即可收发主流聊天软件消息（国内：微信/QQ/企业微信/钉钉；国外：Discord/Telegram/Slack/WhatsApp 等），语气与人设一致。
- **硬边界**：
  - 须走**官方开放接口**（如有）或用户本机显式授权的桥接（如可控的桌面自动化），**不做逆向/破解/未授权抓取**；
  - 每接入一个平台需：① 获得 `api_key / token / OAuth` 的用户授权，② 明确告知收发范围与留存策略，③ 提供**一键断联**与**消息隔离**（私密会话不上云）；
  - 国内平台需实名与风控合规评估，国外平台需遵循其 ToS 与速率限制。
- **前置**：T62 原生窗口 + 消息总线权限模型 + 好感/人设合成（T47）+ `zctx` 隐私标记；
- **验收**：在用户本机完成 2 个国内 + 2 个国外平台的端到端收发复验，断联后不再产生任何网络请求。
- **状态**：`[backlog]` 待主人拍板。

## T52 自主直播

- **目标**：小寻可在用户授权的档期里**自主开播**（画面为立绘 + 声音 + 背景，含与弹幕互动、定时上下播）。
- **硬边界**：
  - 仅在主人**预先授权的时段/平台**内允许推流，需主人一键可中断、可审计回放；
  - 内容边界：不做未授权的真人冒充、版权素材使用需获得许可；
  - 弹幕互动需可配置**发言策略与禁语表**，避免越界。
- **前置**：T62 原生窗口推流管线 + TTS/口型 + 自主发言节奏（T45.2 系列表）+ 审核；
- **验收**：本机完成 30 分钟试播 + 弹幕问答 + 主人一键下播；
- **状态**：`[backlog]` 待主人拍板。

## T53 自主玩游戏 / 自主消遣

- **目标**：小寻可在空闲时**自主选择并进行**轻量游戏/消遣（桌面小游戏、棋牌解谜、养成小游戏等），并可与主人一起玩。
- **硬边界**：
  - 仅在**专用游戏沙箱**内运行，不访问用户隐私目录/账号资产；
  - 需主人显式开启，不在主人不知情时消耗算力/流量；
  - 第三方游戏需获授权，不做外挂/自动化作弊。
- **前置**：游戏沙箱 + 输入抽象层 + 自主决策（idle → play）；
- **验收**：完成 1 款内置小游戏的自主游玩闭环（含开始/中途暂停/结束归档）；
- **状态**：`[backlog]` 待主人拍板。

## T54 自主操控电脑 / 手机

- **目标**：在用户**明确委托的任务**范围内，代主人完成文件整理、软件操作、日程提醒等电脑/手机自动化操作。
- **硬边界**：
  - **零信任 + 可审计**：每一次操控需主人预设**白名单能力**（如“只能在这个文件夹”“只能改这一个配置”），执行前可预览、执行后可回滚；
  - **不做高危操作**（提权、改系统配置、跨账号操作）除非主人二次确认；
  - 手机端需原生 App + 系统无障碍/辅助权限走**官方授权路径**，不做提权破解；
  - 操作日志持久化，主人随时可叫停。
- **前置**：T62 原生客户端 + 能力白名单 + 任务规划 + 安全沙箱；
- **验收**：完成“整理桌面→归档到指定文件夹→一键撤销”三步闭环复验；
- **状态**：`[backlog]` 待主人拍板。

## T55 主动找主人聊天

- **目标**：基于上下文与节律，**主动发起**自然问候/关心/分享（不打扰、不越界），而非仅被动应答。
- **硬边界**：
  - 频率与时段由主人**显式配置**（如“工作时勿扰”“每天只在晚间主动一次”），提供“静音”一键开关；
  - 不在夜间/会议等禁扰时段打扰，不重复刷屏；
  - 主动话题不含隐私窥探，不把云端记忆外泄。
- **前置**：T45.2 节律 + `zctx` + 本地记忆 + 勿扰时段配置；
- **验收**：在本机按主人设定连续 48 小时节律复验（主动次数、时段、勿扰均符合）；
- **状态**：`[backlog]` 待主人拍板。

## 通用闸（适用于 T51~T55 任何一项启动前）

1. **显式同意**：主人书面/面板二次确认“启动 XX 能力”；
2. **范围与审计**：能力边界、白名单、日志与一键撤销齐全；
3. **本机复验**：在主人本机完成端到端复验，非沙箱模拟；
4. **可随时关**：任何时候一键关闭后 0 残留动作/后台任务。

*本 Backlog 不计入 M1-M4 任何阶段进度；待 M1 收敛后由主人按优先级逐项激活。*
