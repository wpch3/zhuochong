# 错误与失败方案索引（持续维护）

本索引不是“测试失败次数排行榜”，而是避免**同一种机制换名字重复试错**的入口。先查索引、对应证据和 `LESSONS.md`；新增错误记录症状、适用范围、原因是否证实、可复现反例、证据、保护措施及重试所需的新条件。没有证据不要把猜测写成根因；不同产品/姿势/源码版本不能混算。确有新参考、材料、机制或可检验假设时允许重新研究，并标注与旧失败的实质区别。资料、错误索引和自动闸只辅助工作，不代替制作、目视、实机或用户要求的其他验收。
