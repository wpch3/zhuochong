# 陪伴节奏、主动性与关系体验规划（P1.9）

更新：2026-10-24。本文件规划桌宠作为陪伴角色的交互边界，不代表主动通知、日程监控、情绪推断或长期关系数值已实现。目标是温暖、可控、有连续性，而不是通过强迫互动留住用户。

## 1. 陪伴模式

候选模式，用户随时可切换：
- **被动陪伴**：仅回应用户在桌宠/对话区的明确操作；默认推荐。
- **轻度主动**：用户允许时，在指定时间段/事件触发低频问候或提示；必须有频率上限与勿扰。
- **专注/勿扰**：不主动打断，弱化动画/提示；只保留用户显式输入所需反馈。
- **暂停/隐藏**：停止语音、通知和主动事件；保留基础设置入口。

不开启模式不得被模型自行改变；应用启动、系统恢复或角色变更时遵守既有用户设置。

## 2. 主动触发规则

候选触发只来自用户明确启用的本地规则：
- 用户主动互动/对话后续；
- 本地计时器或用户建立的提醒；
- 用户授权的应用内事件或系统状态；
- 时间段问候（由用户设置时区/安静时段）。

首版不做：未授权的常开麦克风/摄像头/屏幕监控、读取浏览历史/键入内容推断情绪、未经许可抓取日历/社交账号、因用户长时间离开而持续外呼。

每个主动触发需校验：来源授权有效、勿扰关闭、间隔/频率预算未超、用户仍在指定场景、事件未过期、重复触发已去重。触发原因可供用户查看/关闭。

## 3. 频率、打断与安静体验

- 频率默认由用户控制；产品初期主动消息应极少，提供每小时/每天上限、最小间隔和安静时段设置。
- 角色正在说话、用户正在输入/通话、任务处于高风险确认、用户已勿扰时，不插入主动发言。
- 优先用轻量视觉提示而非突然语音；主动语音需用户明确开启，受 TTS 字符/费用额度控制。
- 连续忽略消息应自动降低频率或进入安静状态，不逐步加码，不在忽略后表达委屈/责备。
- 每次主动内容可以静音、关闭本类触发或设置“以后不要”；不将该动作记作负面关系事件。

## 4. 关系与情绪体验

- 情绪和好感只作为可解释、可重置的体验变量；不影响必要功能、价格、模型质量或用户数据导出。
- 不使用内疚诱导、恐惧失去、占有/嫉妒、暗示用户对 AI 负有照护义务的设计。
- 角色可以表达关心，但不得声称对现实用户有临床诊断能力、真实意识/依赖、持续观察或未经授权的“我一直看着你”。
- 用户长时间离开时采取安静，不制造连续签到压力；不因关机/卸载而惩罚角色状态。
- 关系事件的存储遵守 MEMORY_PLAN：本地、透明、可清空；删除记忆不触发负面角色台词。

## 5. 用户控制与数据

- 一键可见总状态：被动/轻度主动/勿扰/暂停；托盘和工作区状态一致。
- 主动功能按来源/类别独立开关；授权、触发历史和下一次通知规则可查看。
- 任何涉及外部消息、代替用户联系他人、公开发布或付费行为不属于普通陪伴主动性，必须经过独立授权和逐次确认。
- 用户清除触发历史或关闭主动功能后，不再继续使用旧的缓存事件作触发条件。

## 6. 场景测试

- 勿扰期间、用户打字/语音期间、全屏工作或高风险审批中不打断。
- 多个规则同时触发时合并/选择一条并说明，不连发多条。
- 事件过期、重复、时钟/时区变化、设备休眠唤醒、权限撤销后不补发过期消息。
- 连续忽略后主动频率下降；重新开启由用户操作。
- 删除好感/记忆后功能照常工作，不出现惩罚/施压台词。
- 离线/供应商失败时不假装已主动完成，也不自动切换为麦克风监听。

## 7. P1.9 验收拆分

**规划验收（本次完成到文档层）**：陪伴模式、触发源、勿扰/频率、打断规则、关系设计边界和数据控制已定义。

**实现验收（尚未开始）**：模拟时钟/事件测试覆盖去重、过期、静音、频率上限、忽略降频、时区/睡眠变化、撤销授权和删除不施压；所有主动事件可追踪、取消。

**用户评审**：用户评审主动问候的场景/语气/频率和是否默认完全被动；未确认前不打开任何主动推送或日历/外部平台触发。
