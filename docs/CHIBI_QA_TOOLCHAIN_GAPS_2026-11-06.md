## 资料 / 素材缺口

- 更关键的是**可编辑的原画层及遮挡补画**，而不是无目的多收教程：缺可确认的独立衣身底与口袋原层、指间/掌根的可信补画和能够共同连线的痛眼画稿；目前自动抠图、inpaint 和手画试验均不能冒称原始隐藏真值。可以自行隔离设计并按原画风审查，但必须说清不是原真值。手掌需同时考虑指根连接、独立前后遮挡及原大小可辨性，眼睛需保留痛眼语义，不可用删掉分支蒙混过关。
- 已复核官方 [Glue](https://docs.live2d.com/en/cubism-editor-manual/glue/)：对应重合顶点可结合，权重按顶点设置；说明**对应连接**值得研究，不证明自研 zrig 已实现该功能，也不自动解决遮挡或隐藏像素。官方 [表情教程](https://docs.live2d.com/en/cubism-editor-tutorials/expression/) 从上睫毛形变到闭眼、眼白裁剪瞳孔；官方 [Blink 设置](https://docs.live2d.com/en/cubism-editor-manual/eye-blink-settings/) 描述与眼开度相乘的官方语义。上述只能作参考，当前自研引擎参数与素材行为须实际验证，不能宣称官方格式兼容。

## 现有工具和任务流缺口

1. `tools/rig_editor/` 是可编辑组与单轴规则网格的实验工具，静态画布不是 C 渲染；缺真实 C 同步画布、顶点/UV/三角网格、逐点 glue 编辑、遮罩与层序可视化、多轴 keyform、权重绘制及完整动作时间线。不能称为完整骨骼链接/制作工具。现有引擎的 `inherit_from` 和加权变形是不同功能，不等于共享顶点 glue。
2. `zrig_project.py` `.zproj` v1 可保存 rig+PNG 并做安全校验；不支持外部动作/表情文件，不保存可编辑分层原稿或工程历史。不能代表完整作者工程；针对真实含依赖项目的版本迁移和故障恢复仍待做。
3. 预览和 QA 目前有真实 C 帧、有限组合、浅深背景及若干脚本，但非完整状态空间；仍需连续动作、多关节双侧组合、手指全范围、表情/眨眼叠加和目标显示缩放，并对结果实际目视。旧截图有只保存放大局部的风险；下文已改善身体矩阵输出，但其他捕获脚本仍未全改。
4. 一般流程先锁来源/授权 → 分层与隐藏补画 → 绑定/参数/网格/遮罩 → 真 C 极值与中间态 → 个人目视排错 → 安全打包/解包重验 → 完整自动测试/性能 → Windows 真机；记录、代码或局部成功不是其中所有门已完成。真正 Cubism Editor/SDK 是独立路线，当前没有官方 `.cmo3` / `.moc3` 和官方加载证据。

## 本轮实际目视与 QA 改进

针对之前已知的**内移口袋隔离候选**，不是重新以不同参数反复尝试：用分层袖原候选和该候选各采 33 个真实 C 身体姿势，两个浅色拼图 `qa/occlusion_probe_4/{L,R}_split_comparison.png` 每对先原候选、后内移候选。本人打开两侧拼图、中立及数个大角原帧：目标小残角在部分姿势变成较长可识别的口袋边，但口袋静止位置已改变，底色是自动补绘；部分大角袖缝和靠裙子的手指依然模糊/融合，**不是完整修复、不接生产**。拼图只看浅底、16 个单侧二值肩肘腕×body 端点，不代表全部中间态、双侧、动画或其他问题通过。

原工具固定裁 `(290,450,730,720)`，大角伸手会被裁图边缘截断，不能用这张图判定整手。`capture_chibi_body_joint_matrix.py` 现在额外为每个姿势保存 `full/<pose>.png`（真实 C 原分辨率 RGBA 全帧，非放大）；旧裁图格式保留。例 `L_a1_e1_w-1_body-1.png` 显示原裁图之外的伸出手。另对 `L_a-1_e-1_w-1_body-1` 用原帧做最近邻与双三次放大对照，最近邻 `hand-nearest-whole.png` 仍可看到手指边界不清；放大滤镜会改变观察，**不能因此推断模糊的唯一根因**。两次新候选采集的 33 浅色裁图逐像素一致，只覆盖该采样。

采集脚本 `capture_chibi_body_joint_matrix.py` 和 `capture_chibi_expression_mix.py` 现记录采集前后 rig、每个被引用 PNG 和预览程序的 SHA-256/文件长度，若两次不同则拒绝写出采样结果；兼容此前 `poses.json`。路径复用 `.zproj` v1 的相对路径规则，拒绝外部 motion/expression。可查 `pocket_provenance.json`、`baseline_provenance.json`，每份包含 rig 和 46 个 PNG，前后相等。**不是完整构建或安全证明**：其他采集脚本尚未接入、配置/系统库/字体/系统版本未完整锁定，采样中途被更改后恢复也无法发现；文件 SHA 不是签名，不可向旧帧补写成当时的记录。

本轮 `make test` 快闸 2707/0（包含预期负例诊断，example_mod.so 热加载冒烟跳过）；`make test-rig-editor test-zrig-project`、`make test-chibi-capture-provenance test-chibi-pocket-cover-and-pain-branch test-chibi-pocket-split-study test-chibi-topology-studies test-chibi-hires-hand-study` 通过。并未进行 Windows 真机、soak、用户目标显示设置或完整组合视觉验收。定向测试为技术行为和资源哈希，不代替外观。
