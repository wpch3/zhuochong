# UI、桌面软件生命周期与可访问性规划（P1.11）

更新：2026-10-24。本文件补充 `WORKSPACE_IA.md` 的视觉设计、Windows桌面行为和发布生命周期验收；它不是已批准视觉稿，也不改变现有 UI/Live2D 窗口。

## 1. 设计输入与不可变约束

- 先有信息架构和关键流程，再出低保真流程原型，再出高保真设计稿；用户审阅通过后才实现。当前两套风格方向继续以 `ROADMAP.md` 和既有用户决定为准，具体设计稿必须单独提交审阅。
- 角色素材 REF-FIRST；视觉 PNG/字体/图标遵循项目资产规则；不以 emoji、程序绘图、SVG 或深色商务风绕过已定要求。
- 桌宠浮窗保持轻量和透明穿透；主工作区承载生成/代码/代理等复杂操作。工作区打开/关闭不能意外改变角色形态、动作或外观。
- 风格主题不得影响安全提示的可读性、权限信息、错误状态和可访问性。

## 2. UI 组件与状态体系

组件候选：导航/工作区标签、对话消息与来源引用、任务卡/步骤列表、生成参数表单、产物预览/详情、diff与审批、代理run状态、Skill权限摘要、权限中心、成本提示、错误/网络/排队状态、通知/确认对话框、字幕/气泡、设置和诊断视图。

每个组件定义：默认/悬停/焦点/按下/禁用/加载/错误/成功状态；键盘顺序；文字标签；缩放规则；对比度；高 DPI 位图资产；关闭/逃生方式。

交互状态统一使用文案 + 可访问语义，不靠颜色/动画单独传达；不能给未知进度伪造百分比；高风险确认清楚写出动作、路径/对象、外发目标、费用和可逆性。

## 3. 桌面/浮窗布局

- 主工作区适应可缩放窗口；主要操作在窄窗口仍可达，长任务可最小化到任务状态/托盘。
- 桌宠窗大小、位置和置顶属性单独控制；主工作区置顶不自动让角色遮挡全屏应用。
- 气泡/字幕锚定角色安全区，允许调整位置/大小/时长；不挡眼睛/脸；文本过长可折叠/换行。
- 透明背景以 alpha 命中控制鼠标穿透；可交互图标/气泡才拦截点击，空白区域保持项目既定穿透语义。
- 支持多屏与DPI变化：跨显示器移动后正确缩放/定位；断开显示器后窗口回到可见区域；避免丢失到虚拟屏幕。
- 角色隐藏/暂停/退出/语音静音要易于到达；工作区关闭不能悄悄退出重要后台任务。

## 4. 可访问性与低干扰

- 全流程键盘可达，焦点可见；合理的Tab顺序和快捷键，避免快捷键覆盖输入组件。
- 支持文字放大、系统缩放、高对比主题；色彩不是唯一状态编码；字幕支持可读字号和位置。
- 提供减少动态效果/静止角色、静音、仅文字、降低动画频率选项；减少动效不应降低语音/视觉状态可知性。
- 语音输出/通知有独立控制；错误消息可由屏幕阅读技术访问；设置选项有清楚的文字名称。
- 不通过闪烁、强制弹窗、连续通知或高强度动效施压。

## 5. 生命周期与数据安全体验

- 首次运行说明本地数据位置、模型/供应商设置、语音/屏幕/平台权限默认状态；无需完成账户或权限授权就能使用桌宠基础互动。
- 更新前备份必要配置；显示版本和变更摘要；更新失败可回滚；不可静默替换用户素材或配置。
- 崩溃重启时提供任务恢复/清理选择，禁止未确认地重放付费调用、代码命令或外部发送。
- 卸载/清理展示将删除的应用文件、模型缓存、会话、记忆、日志和用户产物；用户数据不与程序卸载混为一项默认清理。
- 设置导入/导出版本化、校验、预览差异；失败不覆盖现有配置；密钥从不进入导出文件。
- 自动启动、更新联网、系统通知等各有显式开关，默认不擅自改变 Windows 设置。

## 6. UI QA 与真机矩阵

- 状态视觉回归：首页/对话/任务/生成/代码 diff/权限/代理/错误/空状态/暂停/取消/更新；浅/深背景与缩放。
- 输入方式：鼠标、键盘、触控（若支持）；屏幕阅读器/键盘导航手动验收。
- Windows：Win10/11目标版本、100/125/150/200% DPI、多屏/混合DPI、屏幕热插拔、休眠唤醒、任务栏/托盘、窗口置顶、透明穿透。
- 性能：冷启动/热启动、空闲CPU/内存、动画FPS、工作区打开响应、长任务资源回收、日志增长和磁盘空间。
- 可靠性：崩溃/断网/供应商错误/更新中断/配置损坏/磁盘满时可恢复且不丢失已保存工作。
- 自动截图/DOM/静态测试只证明相应条件，不替代真实Windows窗口、可访问性手测或用户外观审批。
