# P2.4 主动陪伴与定时/事件自动化规划

更新：2026-10-24。本规划只定义用户可控的本地提醒/事件规则方向，不启用后台监听、平台连接、麦克风/摄像头或系统级监控。提醒通知、桌宠主动说话、调用 AI、执行工具、向外部平台发消息是五种不同权限，必须分别授权。

## 1. 目标与非目标

**目标**：用户能创建、理解、暂停、编辑和删除简单规则；规则触发透明，受勿扰、频率、成本和隐私边界控制；失败、漏触发或重复触发可解释。

**不做**：默认主动监听用户；从桌面内容推断用户状态；静默读取日历/消息/屏幕；无上限自循环；未经确认自动发外部消息/群管/直播控制；以羞辱、内疚或惩罚用户未响应的方式提醒。

## 2. 触发类型和权限分级

| 触发类型 | 示例 | 最小权限 | 风险/默认 |
| --- | --- | --- | --- |
| 定时 | 用户设定每日 20:00 提醒休息 | 本地规则存储/系统时钟 | 低；默认不创建规则 |
| 手动快捷触发 | 用户点击“稍后提醒我” | UI输入 | 低；即时可用 |
| 应用内事件 | 一项任务完成/桌宠闲置 | 本应用事件订阅 | 低至中；用户逐项启用 |
| 系统状态 | 登录、空闲、设备状态 | 需要明确系统权限并说明字段 | 中；不作为首发默认 |
| 外部平台/日历事件 | Twitch/Discord/日历 | 单独连接与最小 OAuth 权限 | 高；完全独立授权，不随本地规则启用 |
| 麦克风/屏幕等观察 | 语音/画面变化 | 独立感知授权 | 高；不属于本任务默认实现 |

单条规则的动作也分层：仅生成本地提醒 → 桌宠发言 → 生成AI内容 → 调用本地工具 → 向外部服务写入。创建规则时显示触发源、动作、数据范围、时间/频率、费用上限、暂停/撤销方式；跨越更高风险动作必须再次单独授权。

## 3. 规则对象与执行语义

规则最小字段：`rule_id`、名称、启用状态、触发器、时区、条件、动作、作用范围、勿扰策略、冷却/频率上限、最大并发/单日次数、预算、幂等键、过期时间、错误处理、最近触发结果、创建/修改时间。

- 规则采用版本化快照；编辑不改变正在执行的那次触发，保存新版本后对后续触发生效。
- 触发用唯一幂等键去重；事件带时间戳和有效期，过期事件丢弃而不是补发一串旧提醒。
- 默认串行；同一规则上一次仍运行时不重入。并行须有明确理由和全局上限。
- 所有等待/执行步骤可取消；取消后不重试付费/外部副作用，除非可确认幂等且用户授权重试。
- 重试只针对明确的瞬态失败，指数退避并有最大次数；平台429/Retry-After按平台要求；永久权限错误暂停规则并通知用户。
- 本地时区/DST变化应明确策略：按本地墙上时间触发一次、不补发跳过的时间；修改时区时显示影响预览。
- 离线时只保留尚未过期的本地提醒；默认不补跑外部动作。重启恢复需防止双重触发。

## 4. 勿扰、频率与用户尊重

- 默认只在用户明确设置的可提醒时段触发；系统勿扰/应用暂停优先级最高。
- 忽略提醒不提高频率，不追问“为什么不理我”；可配置静默、推迟、今日暂停、永久关闭。
- 设置每条规则冷却、全局每日上限、最短间隔和一键暂停所有规则；新规则必须预览估算触发频率。
- 免打扰时可仅记录漏过事件或直接丢弃；不得自动补发积压的一串气泡。
- 用户互动和依恋状态不得用来规避频率限制，付费额度也不得提高主动打扰级别。

## 5. 隐私、日志与取消

- 规则存储本机；无云同步默认。若未来需要同步，需单独评审加密/数据驻留/删除语义。
- 仅保存规则运行需要的数据；日志显示触发时间、来源、规则版本、结果类别、费用和错误码，不记录无关原始消息/屏幕内容。
- 用户可查看最近触发记录、清空历史、导出/删除规则；卸载与撤权处理须由桌面生命周期方案覆盖。
- UI对等待中的规则显示开关和下一次运行；运行中显示取消入口；对没有取消能力的副作用在确认前讲清楚。
- 取消要从定时队列传播到AI生成、TTS与工具执行；取消后迟到结果不得再播放或发送。

## 6. 验收用例

1. 新安装后规则列表为空，未请求日历/平台/麦克风/屏幕权限。
2. 创建本地提醒可预览下一次时间、频率与动作；用户暂停/删除后不再触发。
3. 勿扰期间的触发按用户选择记录或丢弃，不补发积压通知。
4. 同一个事件重复投递只触发一次；过期事件不运行。
5. 快速重复条件被冷却和每日上限挡住；忽略不会加密提醒。
6. 编辑规则后当前运行保持旧版本、后续运行用新版本；能查看版本和结果。
7. 重启/睡眠恢复不会重复执行；DST跳过/重复时刻依配置一次触发。
8. 网络断线、限流、撤权时按退避/停止策略处理，不无限重试，不自动升级权限。
9. 用户在生成中取消，后续 TTS/工具/外发动作都停止或如实标记不可取消状态。
10. 日志不泄露令牌、完整私人消息、屏幕图像或敏感上下文。

## 7. 分期与批准门槛

- **A：本地、手动创建的定时提醒**，不调用AI、不访问外部来源，作为最安全的原型。
- **B：应用内事件规则**，仅允许显式白名单事件和桌宠提示，设置全局频率上限。
- **C：调用AI生成本地内容**，用户单独打开并设单次/每日预算、费用预览、可取消。
- **D：外部服务事件和写操作**，逐个平台/账号/频道授权并重新审查政策；外发动作需人工确认，不能从A/B自动继承授权。

当前只完成规则与验收规划，尚未实现定时器、后台服务或事件连接；无需用户现在测试。进入实现前应明确首批提醒场景、默认静音规则和桌面通知表现。
