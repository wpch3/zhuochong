# 生成区规划：统一任务、队列与产物（P1.2）

更新：2026-10-24。本规划把生图、生文、生音频、生视频及转交代码区的生成请求归纳为统一任务生命周期；不代表生成供应商、生成 UI 或执行后端已经接入。

## 1. 产品边界

- 生成区负责**创建、配置、排队、观察、取消和管理生成任务/产物**；不是代理区、代码执行区或供应商控制台。
- 供应商选择、Key、模型路由和权限由连接/设置管理；每个任务在提交前展示本次实际目标。
- 代码文本可以在生成区起草，但执行、文件写入、构建或运行必须转交代码区审批与隔离流程。
- 生成输出默认保存到用户明确选择的本地位置；不自动上传、发布或覆盖旧文件。
- 提示词/参考素材/结果处理必须遵从其许可与用户授权；不得把模型产物标成已核实事实或已获用户版权确认。

## 2. 统一 GenerationTask 概念

```text
GenerationTask
  task_id, task_type, status, created_at, updated_at
  session_id? / parent_task_id? / template_id? / template_version?
  input_summary, input_refs[], prompt_ref?, provider_id, model_id, model_version?
  parameters, permission_grants[], sensitivity, destination
  budget {token_limit?, char_limit?, cost_limit?, time_limit?}
  progress {stage, completed_units?, total_units?}
  attempts[], cancellation_state, error {category, retryable, may_have_cost?}
  usage {input_tokens?, output_tokens?, characters?, audio_seconds?, images?, video_seconds?}
  cost {amount?, currency?, pricing_source?, pricing_version?, estimated?}
  artifact_refs[], provenance, review_state
```

要求：状态/用量/错误和内容明文分开存储；摘要供列表查看，敏感输入通过受权限保护的本地引用；不把 Key、原始音视频或无限长度输入写入任务日志。

## 3. 生命周期与操作

`draft → validating → awaiting_confirmation? → queued → running → postprocessing → succeeded | partially_succeeded | failed | cancelled | expired`

- **校验**：输入类型、格式、文件大小、授权、供应商能力、模型上下文/额度、目标路径、预算；校验失败时不发请求。
- **确认**：显示发送到哪个服务、涉及哪些素材、成本信息（未知要标未知）、将保存到哪；外发或覆盖前用户确认。
- **排队/运行**：显示当前阶段和排队状态；支持取消；按供应商/用户配置并发上限，防止重复点击产生重复收费。
- **部分成功**：保留已生成的独立产物并说明缺项；不将部分结果标记完整成功。
- **失败/重试**：错误分类为输入/权限/网络/供应商限流/服务端/后处理/写盘/未知；自动重试需幂等且有限次，可能收费时先提示。
- **取消**：尽量停止供应商请求和本地子进程；说明远端供应商是否确认停止；丢弃迟到结果，除非用户选择保存。
- **重跑**：保留输入、参数、供应商/模型版本作为历史副本；明确可能再次产生费用；不能覆盖原结果。
- **清理**：删除任务记录、临时文件、缓存、产物可以分别选择并预览影响。

## 4. 类型分区和类型专属验收

| 类型 | 输入/参数候选 | 产物和验收要点 |
| --- | --- | --- |
| 生图 | 文本提示、获授权参考图、遮罩、宽高比/尺寸/数量、格式 | 预览尺寸/透明度/元数据；项目素材需做机器检查和目视审核；提示词/参考图权限清晰 |
| 生文 | 文本、文档/引用、任务模板、长度/风格 | 区分草稿/校对/最终；保留来源引用和未核实标记；可导出或回到会话 |
| 生音频 | 文本/脚本、TTS音色、格式/采样率、配音或音效类型 | 播放/时长/格式检查；授权音色、商业条款清楚；不可克隆未授权真人；配音文字与音频对应 |
| 生视频 | 脚本、时长/画幅、获授权素材、镜头/字幕/音轨参数 | 进度、预览、导出编码/尺寸；来源/合成标识；中断可保留已完成片段并清理临时文件 |
| 代码草稿（非执行） | 任务描述、选定代码上下文（明确范围）、目标语言 | 生成 diff/代码块后转交代码区审查；此区不执行命令、不直接写项目文件 |

类型/供应商不支持某参数时必须禁用并说明；不能显示控件但悄悄忽略设置。

## 5. 队列、并发与费用

- 用户能看到当前任务、等待数、排序和当前并发状态；同任务重复提交可提示已有运行实例。
- 手动队列优先；后台任务不能饿死交互式对话/桌宠体验；模型/供应商有速率限制时遵从服务器响应并显示退避。
- 单任务预算与全局每日/周期预算独立；接近上限通知，达到上限暂停需进一步确认；预算配置不能被模型输出覆盖。
- 供应商账单回执与本地估算分列显示；缺少价格/usage 时标“未知/估算”，记录价格表版本和更新时间。
- 生成成本包括模型调用、后处理、存储/下载（可获得时）；不得把“免费额度”写成零成本的永久保证。

## 6. 产物库

每份产物记录：artifact_id、父 task_id、类型/MIME、文件名/大小/哈希、创建时间、模型/参数版本（可得时）、来源素材引用、许可/作者声明（可得时）、是否部分结果、校验结果、保存位置。

- 预览不自动导入角色素材或覆盖项目文件；用户确认后才“加入项目/角色”。
- 支持按任务查看、筛选、重命名、复制、导出、删除；导出时提示许可和敏感内容风险。
- 生成文件写入采用临时路径 + 原子重命名；目标存在时新建版本或询问，绝不静默覆盖。
- 产物校验失败仍保留诊断但不对下游标记可用；清理临时文件不删除用户选择保留的最终文件。

## 7. UI 状态和信息分层

- 类型选择与任务模板；输入/参考素材与参数；供应商/权限/费用预览；运行队列；结果画廊/文档列表；产物详情/来源；历史运行记录。
- 列表只展示简短摘要、状态、时间、来源模型、预算/实际成本和下一步；详情中才展示参数和诊断。
- 空/未配置：说明如何连接供应商或用本地功能；等待/队列：显示真实阶段；等待确认：明确副作用；部分成功：逐项标注；失败：可操作错误；取消：说明清理情况。
- 原型需覆盖窗口缩放、键盘焦点、长任务切后台、通知、取消与错误状态；视觉风格按 UI 设计流程交由用户确认，不预设成套视觉稿。

## 8. P1.2 验收拆分

**规划验收（本次完成到文档层）**：任务生命周期、类型区分、预算/费用、权限确认、失败/取消/重跑、产物元数据和覆盖保护已定义。

**实现验收（尚未开始）**：假供应商覆盖请求前校验、队列去重、并发上限、超时/限流、取消/迟到响应、部分成功、预算耗尽、未知费用、产物原子写入、旧结果不覆盖、日志脱敏和删除。

**人工/真机检查**：供应商费用与实际账单一致性、模型产物授权、生成图透明度/角色素材质量、视频长任务资源占用，以及用户能否理解外发/预算/重跑风险。
