## Teen 少女：当前具体缺陷

### 当前可重复机器检查（本轮）

原始结果：`docs/qa/loli_start_audit_teen_2026-11-11.json`（1792 checks / 8 failures，`design_iou=0.9824689612`）。这批失败落在：

1. `armpit_mask` 与 `armpit_mask@2x` 都是全零灰度遮罩，没有有效范围。
2. 左弯前臂 `forearm_bent_l` 与 @2x 色卡偏离：主色距离 71，发现 `#489898` 青色像素（占 8–10%）。
3. `hair_long_back@2x` 白边 4106 px（上限 900），边缘占比 46.2%（上限 30%）。
4. 静止分段合成比整图少 85 px。
5. twin 发型隐藏左右侧发时，虽然有差分件覆盖约 92.6%/93.5%，仍分别露出透明背景 7.64%/18.45%（上限 2%）。

### 已有真实引擎目视证据（最近完整审计 2026-10-31；动态遮挡追踪 11-04）

- 长发 `acc_hair_long` 单件及全身都能看到黑/青/白条状杂边；问题属于该长发件，不是另一图层穿出来。证据：`docs/qa/live2d_teen_audit_longhair_full_2026-10-31.png`、`..._isolated_...png`。
- 抬臂 wave/surprised 时，袖管折痕显硬三角，白夹克—青袖/腋下交界有细窄浮边和碎色；静止全身没有明显大洞不能证明动态接缝通过。证据：`docs/qa/live2d_teen_audit_wave_sleeve_detail_2026-10-31.png`。
- 兜帽长发 `acc_hair_hood_long` 的源链曾把袖口/手形像素带入发件。11-04 动态 C 追踪看到 long+hood-up 的举臂/合手状态仍露出旧袖口/手残留；隔离隐藏目标发件时这些碎片消失、真实动作臂仍在。目标件没有专属物理/变形器；静止/头发摆动及手臂动作需分开归因。证据与细节：`docs/memory/GAPS.md` 的 T67.71 项及 `docs/qa/t67_71_source_trace_2026-11-04/`。
- 已采样的 wave、surprised、tiptoe、heart_hands 可渲染，截图中没有整体姿态坍塌或明显脚底穿地；这只能判定“基本动作能跑”，不代表全动作/全组合无误。
- 头发物理有变化但摆幅偏小；长发重造之后还需复跑时间线/摆动极值。

## Chibi Q版：当前具体缺陷

### 当前可重复机器检查（本轮）

原始结果：`docs/qa/loli_start_audit_chibi_2026-11-11.json`（1585 checks / 28 failures，`design_iou=0.9934918478`）。当前 28 项包括：

- 袖/手部色卡：`arm_l_gusset@2x` 偏色 7%；`arm_l_root` 偏色 12%。
- `armpit_mask` 全零、无有效灰度范围。
- 静止分段合成比整图少 1066 px。
- 踮脚鞋几何不一致：左右鞋口实测升高 73/74 px，而 rig 按 30 px 配套；右常态鞋底 y=1290、地面 y=1291。
- 张嘴 `mouth_cavity` 牙齿 0 px（低于至少 5 px 的检查门槛）。
- 袖下躯干新增内部洞 21261 px（限值 60）。
- 头发摆动 ±12 时身体内部新露洞 226/383 px（限值 20）。
- 腿摆动时裙下接缝分别露底 69/75 px（限值 60）。
- 张嘴下沿与下巴关系失败：QA 提示口部下沿映到 body_full y=559、下巴 y=283，判定为越下巴/偏下风险；须回到脸部坐标和真实引擎动作核验，不能仅用数字归因。
- 两侧腮红不落在 `seg_head` 实心范围（合格要求 ≥80%，当前 0%）。
- twin/pony 发型组合有侧发、后发与躯干补片接管不完整，透明背景露出 6.96%–56.13%（按当前具体分支/检查项）。
- 四个 hood-up 配件外宽只有头宽 1.06 倍，低于 1.10 门槛；帽顶落点也需修正。
- `hand_l_pad`、`hand_r_pad` 仍被判为不符合真素材阈值；结构补片的豁免/报告要明确，不能冒充独立手型。

> 机器检查列出 28 项；以上按问题类别合并展示，不把单个重复左右/发型检查误报成不同根因。详见原始 JSON 逐条记录。

## 记住的制作教训（下一形态必须继承）

1. “ready/能加载”不等于画面合格；机器素材 QA、静态拼回、真实动态 C 画面是不同门，分别报告。
2. 单张合并全身图不等于 Live2D 分层源；先设计含遮挡补图的完整原稿，再拆层/补隐藏像素、锚点、骨骼。
3. 修生成器时确认其全链输入和输出是当前形态专属，不能把 Teen 像素常数/脸部/手件/发型差分偷渡到 Chibi 或 Loli。
4. 每次只说有证据的真实状态：`rig.json` 属自研 `zrig`，不是 Cubism；要声称 Cubism 必须有 Editor 作者工程、正式导出文件和官方运行时验证。
5. 上次版本/README 的统计、历史 QA 和已删素材都需重新核对；当前数据来自本轮当前文件，不拿旧报告混算。
