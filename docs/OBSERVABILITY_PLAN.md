# 运行诊断、延迟与成本观测规划（P0.4）

更新：2026-10-24。本文定义本地诊断的指标与验收口径，不代表指标采集、遥测、仪表盘或供应商计费对账已实现。

## 1. 目标和隐私约束

让用户和开发者能区分“慢在输入/排队/模型/语音/渲染/网络哪里”，看清发生了什么错误、是否会重试、是否产生费用；同时不为了诊断收集超出必要范围的数据。

- 默认**只在本机观测**；不默认上传遥测、崩溃转储、提示词、对话、音频、图像、密钥或文件路径。
- 用户提交诊断包必须逐次确认；提交前显示内容清单并脱敏。不得因开启了某个模型供应商，就推断同意额外上传诊断数据。
- 统计数据与内容分离：优先保存阶段耗时、请求状态、token 数、供应商代号和错误分类；不保存原始消息正文。
- API Key、Authorization Header、OAuth token、原始音视频、完整本机路径、剪贴板和屏幕内容禁止写入普通日志。
- 本地诊断记录可配置保存期限、查看、导出和清除；清除不影响用户明确保留的对话/项目数据。

## 2. 指标字典（首版候选）

| 层 | 指标 | 说明/采集口径 |
| --- | --- | --- |
| 应用 | 启动时间、崩溃/异常计数、版本、配置校验结果 | 不采集机器序列号；诊断包中版本信息由用户确认 |
| 桌宠渲染 | 目标/实际 FPS、帧时间分布、空闲 CPU/内存、资源加载/释放 | 分别测 2D/未来 3D backend；不把 3D 指标并入或改变当前 Live2D 循环 |
| 事件队列 | 当前队列长度、等待时长、过期/合并/拒绝/重复事件计数 | 只记事件类别和来源类别，不记内容 |
| 对话 | 首个模型响应/首 token 延迟、完整响应耗时、取消耗时、成功/失败/超时/限流数 | 计时边界统一，区分本地排队与远端等待 |
| 语音输入 | 采集开始至首个转写结果、端点检测、取消/打断延迟、STT 错误 | 仅采集耗时和状态；默认不存音频或转写正文 |
| 语音输出 | 首音延迟、合成耗时、播放/停止耗时、取消后迟到音频数、TTS 错误 | 文字可见但 TTS 失败应作为降级成功记录，而非整体伪成功 |
| 供应商/网络 | DNS/连接/首字节/响应耗时（可用时）、HTTP 状态/错误类、重试/退避计数 | 不保存 URL query secrets、请求头、正文；供应商标识可本地别名化 |
| 费用/用量 | 输入/输出 token、字符、模型、币种/价格表版本、估算费用、已知的账单回执 | 估算值标记为估算；未知价格不显示假精确金额；不含个人消息正文 |
| 代理/Skill/工具 | 执行步骤数、耗时、审批等待、资源使用、超时、取消、失败与回滚结果 | 工具参数默认摘要或脱敏；高风险调用需关联用户确认记录 ID |

## 3. 计时与成本规则

- 一次用户任务关联 `task_id`，一次对话轮次关联 `turn_id`；阶段 span 只记录起止、父子关系、结果类别及去敏标签。
- 明确区分：事件接收、等待排队、上下文组装、本地推理/远端请求、输出校验、TTS 合成、播放和渲染。端到端时延不能只报模型 API 时长。
- 使用单调时钟测时长；本地墙钟仅用于用户查看时间，系统时钟调整不能让延迟变负数。
- 流式响应至少区分首 token 与完成；语音区分首音与合成完成；取消时记录从取消意图到停止本地输出的时长。
- 重试必须记录原因、次数、退避和幂等性；重试可能重复计费时先提示或按配置禁用自动重试。
- 价格表需保存版本/更新时间；价格换算币种显示来源；供应商未返回 usage 时，只显示“未知”或标注估算公式，不伪造精确用量。
- 日/周汇总由用户选择时区和重置时间；历史账单如供应商回执与本地估算不同，分别展示，不互相覆盖。

## 4. 用户体验与诊断层级

1. **常规状态**：排队、生成、正在播报、完成、停止等；不暴露底层栈信息。
2. **用户可读错误**：说明失败阶段、是否有本地降级、可能是否计费、可重试/取消/切换供应商的选项。
3. **开发诊断**：可打开脱敏本地事件记录，按 task/turn 过滤；禁止默认显示消息正文、音频、文件路径和秘密。
4. **诊断包**：用户显式创建与预览，显示将包含哪些日志/配置字段；秘密扫描通过后才能导出；外发须再次确认。

不以单一“AI 健康分”掩盖错误；不显示无来源的延迟/费用百分比或虚假精确 ETA。预算耗尽、权限拒绝与用户取消是不同状态，不归类为系统崩溃。

## 5. 保留、容量与故障

- 首版建议仅保留有上限的本地滚动诊断日志；具体天数/容量作为实施前的设置决定，不在本文虚构默认值。
- 磁盘写入失败时，主程序仍运行；必要诊断在内存短期保留并告知用户，而不是无限重试写盘。
- 崩溃恢复仅记录非敏感任务状态与明确允许恢复的 checkpoint；不能偷偷续跑付费调用或代码命令。
- 进程退出清理临时内容、音视频缓冲和过期子进程；错误路径也须执行清理。
- 导入/导出诊断数据前检查版本和格式；解析失败不能覆盖已有配置/历史。

## 6. P0.4 验收拆分

**规划验收（本次完成到文档层）**
- 覆盖启动、渲染、队列、对话、STT/TTS、供应商、费用、代理/Skill/工具的指标类别；
- 定义计时边界、错误语义、成本精度标识和敏感数据禁录规则；
- 诊断默认本地、脱敏、可查看/清理；导出/外发需用户同意；
- 明确 3D 未来指标不得侵入当前 2D/Live2D 运行路径。

**实现验收（尚未开始）**
- 用假时钟、假供应商与模拟故障测试 span 耗时、取消、断网、429、超时、重试、费用未知/估算、成本上限和日志脱敏；
- 扫描日志/导出包中不得出现测试密钥、Authorization、正文、原始媒体或未授权路径；
- 删除诊断记录不删除用户选择保留的其他数据；本地日志达到容量上限可安全轮转。

**真机验收**
- Windows 多屏/DPI/休眠恢复下的资源与帧时间、启动/崩溃清理、音频设备切换、CPU/内存占用；
- 用户检查真实费用与延迟是否清楚、日志是否足够排错且没有暴露隐私。
