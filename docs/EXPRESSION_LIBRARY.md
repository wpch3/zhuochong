## 二、星星眼的三个缺陷（要优化，不是重做）

**2.1 虹膜画成了"碎钻/晶体"，不是"星星"。**
`eye_ball_star` 上是几条交叉的白色切面线，1× 看像**玻璃裂纹**或"眼底碎钻"，
而不是"眼睛里有一颗五角星"。用户说"被弄丢了"，很可能就是因为**看不出来是星星眼**。
> 改法：保留蓝色虹膜底（不要整块替换），在虹膜中心画**一颗真正的五角星**（实心 + 内发光），
> 外面再叠 2–3 颗小四角星；碎钻线只留 1–2 条当点缀。

**2.2 正常瞳被整块关掉，眼睛失去焦点。**
`ParamStarEye` 用 `scale -1` 把 `eye_l_ball` 的 alpha 压到 0 —— 深色瞳孔、下半虹膜的亮部都没了，
眼睛变得"发白、发空、没有视线"。
> 改法：星瞳改成**加算/叠加层**（α 上叠加而不是替换），或者只把中心有瞳孔的区域替换、
> 保留外圈渐变；至少让 `ParamEyeBallX/Y` 仍能看出视线方向。

**2.3 星形高光和星瞳是两条互不相干的通路。**
星瞳走 `ParamStarEye`，星高光走互斥组 `eye_hl_style`（默认 `round`）。
`star_eyes` 表情里**没有**切这个组 ⇒ 星星眼时高光还是圆的，两套"星星"不会同时出现。
> 改法：`ParamStarEye` 同时驱动高光组的替换（或者在 `eye_hl_style` 里加一条
> "由 ParamStarEye 自动切档"的绑定），一个参数管到底。

**另外值得加的（用户还没提，但同一类）**：
- 星星眼缺**发光/辉光层**（加算的径向光），现在只是换了图案，没有"眼睛亮了"的感觉；
- 8 颗 ✨ 全部是同一张图，只有大小不同（0.5 / 0.34 / 0.225）与相位不同，
  形状没有变化，密集时会读成"复制粘贴"。

## 三、表情与特效的"四层结构"（加新效果都按这个加，不许临时开洞）

从 Live2D 的常规做法归纳，一个"眼部/面部特效"最多四层，**每层职责单一**：

| 层 | 作用 | 载体 | 例 |
| --- | --- | --- | --- |
| **L1 瞳/眼型** | 换掉或叠加虹膜、瞳孔、闭眼线 | `eye_?_ball*`、`_closed/_smile/_pain` | 星星瞳、爱心瞳、圈圈眼 |
| **L2 眼内细节** | 画在虹膜里的图案（碎钻、星屑、泪光） | 同上或独立小件 | 泪汪汪、星星碎片 |
| **L3 脸周特效** | 眼睛周围/头顶的加算符号 | `fx_*`（层 300+） | ✨、💢、汗滴、音符、Z、爱心 |
| **L4 面色/呼吸** | 腮红、唇色、皮肤明暗 | `blush_*`、`cheek` | 脸红、发青、惨白 |

**规矩**：一个"效果"= 一条参数门 + 若干层，**不许**为了一个效果去改别人的层；
特效件一律放 300+，`Param<特效>` 为总闸（现在的 `ParamStarEye` 就是这个范式，照抄即可）。

## 五、验收闸（新效果入库时必须过）

1. **一个参数一门**：`ParamXxx` 为 0 时，该效果的所有件 alpha 必须为 0（机检：
   逐件在参数为 0 时采样 alpha，必须 ≡0）；
2. **不许抢别人的层**：特效件层号 ≥300，且不得遮挡眉毛/眼线（几何闸：与眉/眼线包围盒重叠时，
   透明度按距离衰减或直接置 0）；
3. **眨眼/说话时不穿帮**：`ParamStarEye=1` 时连打 3 次眨眼 + 5 个口型，逐帧无残影；
4. **逐档目视**：0 / 0.5 / 1 三档 5× 放大图（`docs/qa/` 存档），没有"看不出来"的档位；
5. **退出干净**：效果结束后所有 `fx_*` 回到 alpha 0（残留 = 红）。
