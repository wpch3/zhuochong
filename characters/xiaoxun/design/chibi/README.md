# 小寻 Q 版形象参考（桌宠版先行）

## 当前交付

- `desktop_pet_base_2026-10-31.png`：桌宠 Q 版正面、idle 基础形象。用户确认参考 `image-16.png` 的比例；本稿将头部（含头发）约占全高一半，躯干与短腿合占另一半，避免漂浮大头或长身比例。
- `desktop_pet_walk_side_2026-10-31.png`：同一形象的侧面行走姿态参考，供桌宠动作/朝向设计使用。

这两张是**新生成的设计参考图**，不从旧的 `forms/chibi/sprites/body_full.png` 派生；也不是可直接拆件的生产 sprite。桌宠版本先固定短发、白/青 hoodie、奶油色衬衫、海军蓝百褶裙、双青条白袜与青白鞋；不添加猫耳、尾巴、双马尾、马尾或帽上状态。

## 设计约束

- 身份基准：`../design_sheet_short.png`（小寻少女短发全身设定）。
- 画风与比例方向：本轮用户提供的桌宠状态图/单角色样例；只参考小尺寸下的头身比例、轮廓和精致度，不复制参考角色、女仆装、配色、配饰或视觉资产。原始附件不复制进仓库。
- 桌宠 Q 与 Live2D Q 是两种不同用途的设计，当前只做桌宠 Q。Live2D Q 后续应重新规划可拆分的发型、眼口、遮挡与形变空间，不直接把桌宠正面图当作 Live2D 底图。
- 图像生成稿在进入生产前，须由用户确认角色身份与比例；随后还要按 Reference-Driven Development 对照全身参考、逐项检查脸/发/服装，拆件、遮挡与运行时截图验收。

## 下一步

1. 以这两张确认后的桌宠 Q 版方向补充正侧/必要的基础姿态与表情参考，不将一张生成图误当作完整动画素材集。
2. 单独提出 Live2D Q 版设计稿；优先保证面部五官、刘海、侧发、兜帽遮挡和可分层结构可实现，再进入拆件。
3. 由美术/用户确认后，再决定哪些内容重画进真正的生产 sprite；未经授权的外部项目截图和美术资产不进产品。
