# 小寻 Loli — 当前参考与版本归档

状态：**v1.1 比例参考已由用户选定，作为自制 Live2D 的唯一当前制作基准。**它仍是完整概念图，不是分层原画或 Cubism 模型。

## 新参考（当前制作基准）

- `concept_front_proportion_v1_1.png` — 用户选定的完整正面比例参考，1280×1920 RGB、白底。短百褶裙位于自然腰线，上衣放在裙外，双腿靠拢。后续角色拆件与补画必须以它为准。
- `authoring_v1_1/` — 第一轮透明底轮廓校验稿与浅/深底预览。它只分离了画布外背景，角色内部仍是单张扁平图，不是 Live2D 拆件。
- **不要对白色背景做白色色键抠图**：服装也有白色区域，会损伤衣缘。制作透明源稿时应沿角色轮廓绘制/重建透明背景，并检查衣物边缘。

## 制作进度

`authoring_v1_1/reference_v1_1_alpha_edge_connected.png` 是从新参考生成的透明背景检查副本：只移除与画布边缘连通的近白背景，白色夹克/上衣封闭区域保留。它本身仍是扁平整图。

`authoring_v1_1/head_pass_02/` 是当前的**实际可编辑分层迭代**：完整 1280×1920 OpenRaster（ORA）文件，独立分出 whale 发夹、左右眉、左右眼、鼻印、闭嘴线稿，并保留隐藏的 NEW v1.1 参考层。眉眼位置按原图坐标放大复核；鼻/嘴只选深色笔画，避免上一版出现脸颊色块。拼合 QA 为 80 像素 RGB 差异超过 2 级、最大通道差 50。指标比上一版（67/41）更大，不能用来声称质量提升，只作文件拼合诊断。ORA 可由 Krita/GIMP 打开，**不是 PSD/PSB**。具体情况和限制见 `authoring_v1_1/head_pass_02/README.md`。

`head_pass_01/` 保留为历史记录，已经标注 **superseded / 不要继续制作或用于 rig**：本人目视后发现眉眼坐标错误且鼻嘴带入过大的肤色块，第二版已更正明显问题。这仍只是早期 WIP：眉眼内部遮挡、刘海交叠和底下隐藏皮肤/眼睑并未重绘；脸底插值不是手绘。除七个脸部/夹子选区外，刘海、后发、脸型、颈部、躯干、外套、袖手、裙腿、袜鞋仍融合在单张底图里，未完成手绘补画，更不是可变形生产原画。

## 已舍弃内容与模型状态

根据用户要求，已舍弃基于旧版概念制作的空白 ORA 脚手架、旧版七个面部拆件/插值补色、相关清单与旧版本专用生成/检查脚本。它们不适用于 v1.1，也不再是当前交付。当前没有分层 PSD/PSB、Cubism Editor 工程、ArtMesh、参数、物理、`.moc3` 或运行时模型。

## 下一步制作顺序

1. 以新参考重绘/制作透明、可编辑的完整分层源稿；手工保留白色衣料，补齐头发、脸、衣物交叠与关节的隐藏区域。
2. 对新源稿按面部、发束、身体、袖子/手、裙、腿、袜鞋分层，做静止拼合与偏移检查；避免把扁平整图拆成假的模型部件。
3. 输出兼容 Cubism 的 PSD/PSB 后，再由官方 Cubism Editor 建网格、变形器、参数、物理、表情/动作并验证导出。尚未找到官方 Editor 环境之前，不宣称已进入 Editor 或完成真 Cubism。

`concept_metrics.json` 记录新旧参考的尺寸、哈希及限制；`SHA256SUMS.txt` 是本目录完整性清单。
