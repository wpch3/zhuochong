## 重要边界

- 这是 T2.2.1 的第一阶段概念稿，不是已完成的萝莉模型。
- `forms/loli/` 尚无生产素材或 `rig.json`；`forms.json` 必须继续保持 `planned`，不能把整张图当作一个“骨骼模型”或为了切换可见而谎报 `ready`。
- 这不是 Live2D Cubism 工程：无分层 PSD/KRA、无 ArtMesh/Deformer 工程、无 `.cmo3`、`.moc3`、`.model3.json`。它也不是项目自研 `zrig` rig。
- 不能直接缩放/复制 Teen 或 Chibi 生产部件来填萝莉；这两个形态本轮体检均未全绿，且比例/关节几何不同。

## 接续施工顺序

1. 以此概念为身份锚点，先校正到 848×1360 规范画布并复核可见轮廓/头身比（目标约 1:4，测量口径写进 anchors）。
2. 做前/侧/背全身设计与统一视角表情差分，锁定被遮挡区域也已补绘的分层源稿。
3. 从源稿独立拆脸底、左右眉/眼/睫毛/眼球/高光、五档口型、前发分束/侧发/后发/呆毛/鲸鱼夹、颈躯干/夹克/袖口夹层/手、裙摆/腿/袜/鞋；隐藏部位补图，左右独立，透明像素和边缘逐件检查。
4. 建 `forms/loli/design/anchors.json` 与形态专属 `form_art.json`，再在隔离区跑拆件链、静止拼合与 QA；不继承 Teen 固定像素锚点。
5. 生成萝莉专属 rig；核查部件数、参数、动作/表情的真实数量，不把机制存在说成素材存在。
6. 用真实 C 引擎看眨眼、视线、说话、抚摸/摸头、手臂/裙摆动作、头发物理及组合；通过后才更新 `forms.json` 为 ready。
7. 若用户要求真正 Cubism，还需单独取得官方编辑器工作环境并走 `.cmo3`→导出与官方 Viewer/SDK 验证；`zrig` 不能冒称 Cubism。
