# ZhuoPet 设计文档

## 1. 产品原则

1. **桌宠优先，界面其次**。用户每天开着的是角色，不是控制面板。没有卡片、没有侧栏、没有参数表。
2. **先能用，再完美**。旧项目最大的问题是所有代理都在等“美术完美”才提交，最后什么都没交付。ZhuoPet 的路线是：先让角色在桌面上活起来，再逐步加细节。
3. **本地优先**。不注册、不上传、不需要 Key 也能聊天。云端是可选增强。
4. **所有状态可见但不喧宾夺主**。本地/云端、情绪、亲密度都有小字提示，但不会糊用户一脸。
5. **原创**。角色、模型、代码都是本项目原创，不使用任何商业 Live2D 素材。

## 2. 角色设计

### 小寻（默认）
- 星屑猫娘，银紫头发、蓝紫眼睛、奶油色连帽卫衣 + 藏青百褶裙、薄荷绿鞋子。
- 猫耳、呆毛、双马尾、猫尾、星星发夹、星星伙伴。
- 性格：活泼、嘴硬心软、傲娇、黏人。喜欢草莓牛奶、晒太阳、被摸头；讨厌香菜、冷暴力、一个人。
- 说话风格：短句、带「哼」「喵」，偶尔毒舌但绝不真的伤人。

### 月见
- 月下读书人，蓝紫长发、紫罗兰眼睛、午夜蓝配色。
- 温柔、从容、有画面感，偶尔冷幽默。喜欢深夜、旧书、热可可、雨声。

### 双喜
- 元气小太阳，蜜桃色头发、金色眼睛、暖色运动装。
- 热情、直接、感叹号多，爱火锅和游戏。相信快乐是正经事。

### 小尘
- 软绵绵的瞌睡虫，薄荷色头发、绿色眼睛、薄荷运动装。
- 说话慢慢的、软软的，经常打瞌睡。温柔、包容、不催人。

四个角色共用同一套骨架和表情系统，只换配色、配饰、性格和语音参数。这是“一个模型，四个灵魂”。

## 3. 视觉设计

### 桌面
- 暮色星夜：深紫渐变 + 星星 + 月亮 + 模糊光斑 + 网格 + 暗角。
- 晴日窗边：浅蓝到奶油。
- 樱花午后：粉到淡紫。
- 所有面板是白色玻璃拟态：高透明、backdrop blur、圆角 22–28px、柔和阴影。

### 字体与颜色
- 系统字体：PingFang SC / Microsoft YaHei / Noto Sans SC。
- 主色：`#7C6CF0`（紫）、`#FF8FBE`（粉）、`#5FC9B8`（薄荷）、`#F5C56B`（金）。
- 文字：`#2C2545`，次要 `#6D6486`，弱化 `#9A92AE`。

### 动效
- 气泡从角色头顶弹出，带小尾巴。
- 摸头冒爱心，投喂冒星星，戳一下冒汗，转圈冒音符。
- 打字时三点跳动；云端流式输出带光标。
- 所有动画尊重 `prefers-reduced-motion`，设置里也可以手动关闭。

## 4. 交互设计

| 用户动作 | 反馈 |
| --- | --- |
| 移动鼠标 | 她的视线和头会跟着你 |
| 点头部 | 摸头：开心、爱心、说一句、马尾/呆毛弹一下 |
| 点身体 | 戳一下：惊讶、冒汗、说一句 |
| 按住拖动 | 她被拎起来，腿会晃，松手后位置记住 |
| 双击 | 打开聊天 |
| 右键 | 小菜单（说话/摸头/挥手/换装/性格/记忆/设置/隐藏/退出） |
| 不理她 | 待机张望、换重心；5 分钟后睡着；睡后冒 Z |
| 太久不理 | 主动搭话（可关） |

## 5. AI 人格与对话

### 本地大脑
- 意图识别：问候、关心、喜欢、想念、难过、开心、生气、感谢、夸奖、冒犯、食物、睡眠、游戏、工作、天气、时间、笑话、帮助、身份、年龄、爱好、再见、默认。
- 情绪由意图和关键词决定，并影响表情、回复语气和亲密度。
- 记忆抽取：`记住…`、`我叫…`、`我喜欢…`、`我讨厌…`、`我住在…`、`我的生日是…`。
- 回忆：问「你还记得吗」会复述名字、喜好、讨厌和其他记忆。
- 遗忘：`忘掉…` 会从记忆里删除相关条目。
- 关系等级：初识 → 熟络 → 亲近 → 挚友 → 灵魂搭档，每 20 点亲密度升一级。

### 云端
- 任何 OpenAI 兼容的 `/chat/completions` 接口。
- 系统提示词包含角色人格、用户信息、时间、情绪、记忆和说话风格。
- 流式输出；失败自动切回本地大脑并提示原因。
- Key 只存本机，导出备份时清空。

### 安全边界
- 不讨论政治敏感话题，不生成露骨内容。
- 不主动索要隐私。
- 用户难过时先安慰，不急着讲道理。

## 6. 记忆与关系

- 记忆条目分：喜欢、讨厌、名字、身份、其他。
- 每条记忆可以手动删除；可以一键清空。
- 重要时刻（第一次见面、关系升级）会记录在「一起经历的时刻」。
- 所有记忆只存本机，可导出/导入备份。

## 7. 语音

- 使用浏览器 `speechSynthesis`，不依赖任何服务器。
- 每个角色有自己的音高/语速基准（小寻 1.35/1.02，月见 1.05/0.92，双喜 1.5/1.12，小尘 1.15/0.85）。
- 用户可以在设置里选择音色、调语速/音调/音量、试听。
- 语音输入使用 `webkitSpeechRecognition`（Chrome / Edge）。
- 说话时嘴巴会动；没有语音时也会做口型。

## 8. 桌面端

- Electron 主窗口：透明、无边框、置顶、托盘。
- 小窗桌宠：`?mode=pet`，只显示角色，可鼠标穿透。
- 托盘菜单：显示主窗口、小窗桌宠、打开聊天、设置、模型工坊、鼠标穿透、总在最前、退出。
- 全局快捷键：`Ctrl+Alt+Z` 主窗口显隐，`Ctrl+Alt+T` 穿透，`Ctrl+Alt+P` 小窗桌宠。
- 窗口位置记忆。

## 9. 无障碍与性能

- 减少动画开关 + `prefers-reduced-motion`。
- 所有按钮有 title / aria-label。
- 动画只写 SVG transform/opacity，不触发 React 重渲染。
- 弹簧用固定子步长积分，任何帧率下都稳定。
- 移动端自适应：dock 可横向滚动，侧栏变窄，模型工坊隐藏侧栏。

## 10. 路线图

1. 更多服装和配饰（水手领、围巾、耳机、尾巴可关）。
2. 更多动作（伸懒腰、打坐、趴下、转圈、比心）。
3. 更多角色（沈予、双喜的妹妹、桐生、小尘的朋友）。
4. 桌面视觉理解：感知全屏游戏/专注状态，安静陪伴或主动提醒（需用户授权）。
5. 聊天软件桥接（OneBot / Discord / Telegram），统一消息协议。
6. 商业 `.moc3` 加载器（需要 Cubism 运行时授权）。
7. 3D/三渲二角色（VRM）作为可选渲染通道。
8. OBS 虚拟摄像头、自主直播（需主人显式授权）。
9. 手机端（ADB / 无障碍）远程感知与提醒（需主人显式授权）。

> 第 4–9 项都涉及外部能力，默认关闭，且必须经过主人显式授权。ZhuoPet 不会偷偷控制任何设备。
